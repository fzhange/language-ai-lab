## 导入清单的必要材料

1. 来源单位与权利方、原题名称、考试类别、年份/地区/卷别、官方来源 URL；阅读原文的完整使用范围（包括配图和第三方引文）。
2. 可验证的书面授权或明确允许在本站复制、公开展示、在线答题及提供解析的许可原文和期限；留存授权编号、证据位置、有效时间及许可区域。不得只根据外站提供的下载链接推断授权。
3. 核对题干、四选项、标准答案、出处及解析；阅读题必须有完整文章与配套题。校对任何复制/编辑限制。
4. 授权到期或被撤销时立刻从服务端清单移除；交卷不应以被撤销的来源继续发题。审核通过前，不向 `exam_content/manifest.json` 增添题目。

上线前由内容负责人重新核验授权文件和发布日期；使用本地已确认许可的题目，不从第三方网站运行时抓取。仿真原创题必须显著标注“AI 仿真原创”，避免与官方机构存在关联的暗示。
