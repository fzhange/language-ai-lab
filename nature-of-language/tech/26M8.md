## embed（动词词根）

> **embed** /ɪmˈbed/ 动词：把某物**牢牢嵌入 / 埋入**到另一物之中，使其成为一部分。

核心语义逻辑：**放进去 + 固定住**，强调"嵌入后融为一体、不易分开"。抓住这个"核心动作"，其它用法都能推出来：

| 场景 | 例句 | 理解 |
| --- | --- | --- |
| 物理嵌入 | The nail was **embedded** in the wall. | 钉子牢牢嵌在墙里 |
| 技术嵌入 | **embed** a video in a webpage | 把视频嵌入网页（成为页面的一部分） |
| 抽象嵌入 | values **embedded** in the culture | 深植于文化中的价值观 |
| AI 语境 | **embed** text into a vector | 把文本"嵌入"成向量 |

**词性推导（这就是 nature，不用死记）：**

- 动作 `embed`（动词：嵌入）
- 这个动作本身/结果 → 加 `-ding` → **embedding**（名词：嵌入这件事 / 嵌入得到的向量）

一句话串起来：**embed（嵌入）这个动作 → embedding（嵌入的结果 = 向量）**。

## embedding

> **embedding** /ɪmˈbedɪŋ/ 名词：嵌入向量，简称「向量」

**例句：**
> Vector search finds the items whose embeddings are closest to a query embedding.
>
> 翻译：向量搜索，找出**条目向量**和**查询向量**距离最近的那些数据。

**通俗拆解：**

1. **embedding（数据侧）**：把文本/图片转成一串数字数组（高维向量），这串数字就叫 `embedding`。
   - item's embeddings：库里每条数据生成的嵌入向量。
2. **query embedding（查询侧）**：用户输入查询语句，同样跑一遍模型，转换成向量 → **查询向量 query embedding**。
3. **向量搜索逻辑**：不做关键词匹配，直接**算向量之间距离**；距离越小，代表语义越像。

**极简笔记版（方便记忆）：**

- embedding：把文字变成一串数字，用来代表语义
- query embedding：用户查询转出来的向量
- vector search：计算向量距离，返回语义相似结果

**例句对照：**

| 英文 | 中文 |
| --- | --- |
| Generate embeddings for documents | 为文档生成嵌入向量 |
| query embedding | 查询向量 |
| embedding similarity | 向量相似度 |

> 小提示：中文资料里，绝大多数时候直接译作**向量**，「嵌入」是字面直译。
