# compact 
> The robot features fluid movement, compact yet exceptional.

“compact”常见含义分为两大类：既可作形容词表示小巧紧凑的，也可作名词表示小物件、合约，同时能作动词表压缩，多个义项日常高频使用。
**音标**：英 /ˈkɒmpækt/（adj./n.）；/kəmˈpækt/（v.），美 /kəmˈpækt, ˈkɑːmpækt/

**核心含义及用法**
1. 形容词 (adj.)：小巧紧凑的；体积精简但性能不俗（你给出推文语境中正是此义）
    - 搭配：compact design（紧凑设计）；compact size（小巧尺寸）
    - 例句：The robot features fluid movement, compact yet exceptional.（这款机器人动作流畅，体型小巧却性能出众。）

2. 名词 (n.)：小型便携物品；契约，协定
    - 搭配：powder compact（粉饼盒）；social compact（社会契约）
    - 例句：She carries a compact in her handbag for touch-ups.（她手提包里放着粉饼盒方便补妆。）

3. 动词 (v.)：压紧；压实，使密集
    - 搭配：compact soil（夯实土壤）；compact data（压缩数据）
    - 例句：Snow compacts into ice under heavy pressure.（积雪在巨大压力下压实成冰。）

# DSL (Domain-Specific Language) VS GPL (General-Purpose Language)
对比 Java/Python 这类**通用编程语言 (GPL)**，DSL**只针对某一个领域**设计，语法贴近业务，简单专用。
- **外部 DSL**：独立语法文件
    ✅ 例子：**SQL、HTML、正则表达式、Dockerfile、Makefile**
- **内部 DSL（嵌入式 DSL）**：嵌入在通用语言里
    ✅ 例子：Elasticsearch Query DSL、Spring Boot 配置、Gradle 脚本

# DDL = Data Definition Language VS DML
中文：**数据定义语言**属于 SQL 的一部分，用来**定义数据库结构（库、表、索引）**，不操作表里的数据。常用指令：
- `CREATE` 创建
- `ALTER` 修改
- `DROP` 删除
    区分：
- DDL：改**表结构**
- DML：增删改查**表里数据**（INSERT/UPDATE/DELETE）

# parallel = simultaneous ≠ concurrent
> **Concurrent（并发）**：多个任务**交替穿插执行**，不一定同一时刻运行。
  单核 CPU 多任务分时调度就是典型并发。
  **Parallel（并行）**：多个任务**同一时刻同时运行**。
  必须依靠多核 / 多处理器，硬件上真正同时干活。
  
 > Simultaneous 同时的（通用形容词）
 >英文本义：**happening at exactly the same time**（同一时间发生）
   ✅ Parallel execution 属于 simultaneous；
   simultaneous 是普通英文词汇，**不是计算机专业术语**

# conduit（水或电线的）管道
> A channel is a typed conduit through which goroutines can communicate.

> - `through which` 是「介词 + which」引导的定语从句
> - 正常语序还原一下：`goroutines can communicate through the conduit`（goroutines 可以穿过 / 经由这个管道通信）

| 定语从句写法                                  | 还原后的正常语序                          |
| --------------------------------------- | --------------------------------- |
| the pen **with which** I write          | I write **with** the pen          |
| the house **in which** he lives         | he lives **in** the house         |
| the tool **by which** data is processed | data is processed **by** the tool |
