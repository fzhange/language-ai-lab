# 融合关系词完全理解手册（what / who / where / when / how / why / -ever）

> **写给谁看**：`what / where / when / how` 这些词，看到时一会儿觉得"在问问题"、一会儿又不像在问，彻底分不清的学习者。
>
> **核心思路**：融合关系词和特殊疑问句用的是**同一批 wh- 词**，但它们干的是**相反的事**。一句话抓住本质——**疑问词在"发问"（要倒装、是问句）；融合关系词在"打包"（不倒装、是名词）**。先把这条界划清，后面全都顺了。

---

> [!IMPORTANT]
> ### 🧠 底层逻辑：融合关系词 = 自带先行词的关系词
>
> 普通关系结构里，**先行词**和**关系词**是分开的两个词：
>
> ```
> the place    where   I live
>  ↑先行词       ↑关系词
> ```
>
> **融合关系词**把先行词**吞进了自己肚子里**，一个词同时干两件事：
>
> ```
>      where    =    the place   +   where
>      ↑一个词         ↑先行词        ↑关系词
> ```
>
> 👉 于是它引导的从句，整体就是**一坨名词**（= the X that…），可以塞进句子当主语/宾语/表语。
>
> **一句话本质**：融合关系词 = **the X that** 二合一。`what`（= the thing that）只是其中"X = 物"的那一格。

---

## 一、先划清三条界：融合词 ≠ 疑问词，≠ 倒装，≠ 回溯

这是本篇最重要的部分。融合关系词最大的"坑"，是它和特殊疑问句**长得像**。但只要盯住"**有没有倒装、是不是在发问**"，一刀就能切开。

### 1.1 融合词 vs 特殊疑问词：同一个 wh-，干**相反**的事

```
【特殊疑问词：在"发问"】
What  did  he  buy?
 ↑    └助┘└主┘        → wh- 词把助动词逼到主语前（倒装）
 整句是一个问句，句尾 ?，在向外索取信息

【融合关系词：在"打包"】
I know  what  he  bought.
        ↑    └主┘└动┘     → wh- 从句内部是规规矩矩的"主语+动词"，没倒装
 整句不是问句，what 从句被打包成名词，当 know 的宾语
```

| | 特殊疑问词 | 融合关系词 |
|---|---|---|
| **在干嘛** | 发问，索取信息 | 打包，把一坨内容当名词用 |
| **整句是** | 问句（句尾 `?`） | 陈述句（wh- 从句只是其中一个成分） |
| **从句语序** | **倒装**（助动词/be 跑到主语前） | **不倒装**（主语+动词，正常陈述语序） |
| **典型** | What **did he** buy? | I got what **he** bought. |
| **= 什么** | （在问那个未知物） | = the thing that he bought |

> [!TIP]
> ### 一眼判断法：wh- 后面是"**助动词+主语**"还是"**主语+动词**"？
> ```
> What  did you  want?     → did(助)+you(主) = 倒装 → 疑问句
> I know what you  want.   → you(主)+want(动) = 没倒装 → 融合词
> ```
> **倒装 → 疑问；正常语序 → 融合。** 这是最快的切分刀。
>
> ⚠️ 唯一的同形情况：**wh- 词本身就是主语**时（`Who broke it?` / `I know who broke it.`），两边都是"who+动词"、都不倒装。这时改用第二把刀——**整串是不是一个独立问句（句尾 ?、在向你要答案）**？是 → 疑问；它只是大句子里的一个成分 → 融合。

### 1.2 融合词 vs 倒装：一个**偏不动语序**

特殊疑问句之所以要倒装，是因为它属于《倒装手册》讲的那套机制——**句首被抢占，助动词就得前移补位**。

而**融合关系词恰恰相反：它从句内部死守陈述语序，绝不倒装**。

```
✅ I know what he wants.        （he wants，正常语序）
❌ I know what does he want.    （这是把疑问句的倒装错塞进来了）
```

> [!WARNING]
> ### 推论：融合词里**没有 do-support**
> 既然不倒装，就**不会借 do/does/did**：
> ```
> ✅ Tell me where she lives.        ❌ Tell me where does she live.
> ✅ I forgot what time it started.  ❌ I forgot what time did it start.
> ```
> 一旦你在融合词从句里写出 `do/does/did + 主语`，几乎可以肯定写错了——你把"疑问句的倒装"误装到了"融合词的打包"上。

### 1.3 所以：融合词**不牵扯"还原 / 回溯"**

《特殊疑问句手册》里有个"还原/回溯"——把倒装过的问句**复位**回陈述句。**那套东西对融合词不适用**，原因很干脆：

> **回溯的对象，是"被倒装动过的语序"。而融合词压根没倒装过，没有任何语序需要复位。**

理解融合词只需要**一步**，而且是性质完全不同的一步：

```
不是"还原"（逆转某个变换），而是"替换"（同义改写）：
   把融合词直接换成它等价的 "the X that"，意思不变。

   I got what I wanted.
        ↓ 替换
   I got the thing that I wanted.    ← 同义，结构现形
```

> [!NOTE]
> **"还原"和"替换"的区别**：
> - 疑问句的**还原** = 撤销一个真实发生过的语序变换（倒装）→ 是"逆运算"。
> - 融合词的**替换** = 把 `what` 当成 `the thing that` 的缩写，展开来看 → 是"同义改写"，从头到尾没有任何变换被施加或撤销。
>
> 👉 所以读到本篇任何例子，心里做的都只是"**换成 the X that**"，**不要**去想"撤销倒装""填回答案"那一套——那是疑问句的事。

## 二、总表：每个融合词 = "the 某类东西 + 关系词"

划清界之后，剩下的就轻松了。不用背词，只问一句：

> ### ❓ 核心问题：你要打包的这坨东西，**属于哪一类**（物/人/地/时/方式/因/选择）？

类别定了，词就定了；看到词，也立刻知道它吞了哪类先行词。

| 这坨属于… | 通用先行词 | 融合关系词 | = 替换成 | 例子 |
|---|---|---|---|---|
| **物 / 事** | the thing(s) | **what** | the thing that | I got **what** I wanted. |
| **人** | the person(s) | **who** / **whoever** | the person who | **Whoever** comes is welcome. |
| **选择（限定范围）** | the one(s) | **which** / **whichever** | the one that | Take **whichever** you like. |
| **地点** | the place | **where** / **wherever** | the place where | This is **where** I live. |
| **时间** | the time | **when** / **whenever** | the time when | Sunday is **when** I rest. |
| **方式** | the way | **how** | the way (in) which | This is **how** I did it. |
| **原因** | the reason | **why** | the reason (for) which | That's **why** I left. |

> [!TIP]
> ### 这台机器能"推"，不用背
> - 想打包"一坨**地点**" → 念 the place where → 压成 **where**。
> - 看到 `where` → 立刻知道 = the place where，整句成分秒清。
>
> 英语只是给不同**类别**的先行词，各配了一个专属融合词。

## 三、`-ever`：同一台机器的"全称 / 让步"加强版

`whatever / whoever / wherever / whenever / whichever / however` 不是新词，就是上面那些词**加了 `-ever`**。`-ever` 只做一件事——**把"那个"放大成"任何一个 / 无论哪个"**（详见《后缀.md》里 `ever` 的逻辑）。

它带来两种读法，靠**位置**区分：

```
【读法①：名词性 = anything / anyone that…（"任何…的"）】
You can take whatever you want.
= You can take anything that you want.   （整坨当 take 的宾语 → 名词）

【读法②：状语性 = no matter what…（"无论…"，让步）】
Whatever you do, I'll support you.
= No matter what you do, I'll support you.   （被逗号甩在主句外 → 让步状语）
```

> [!TIP]
> 占了**主语/宾语/表语**的位置 → 读法①（名词）；被**逗号甩在主句外作铺垫** → 读法②（让步状语）。本质都是"全称化"，没变。
>
> 注意：`-ever` 从句**同样不倒装**——`whatever he says`（he says，正常语序），不是 `whatever does he say`。它仍是融合词，第一章那三条界全部适用。

## 四、整坨从句是什么词性？名词为主，地/时/-ever 可作状语

| 融合词 | 打包出的词性 | 能放哪 | 例子 |
|---|---|---|---|
| what / who / which | **名词** | 主语 / 宾语 / 表语 | **What** matters is effort.（作主语） |
| where / when | 名词，也常作**状语** | 名词位；或当地点/时间状语 | I'll go **where** you go.（地点状语） |
| how / why | 名词，最常接在 be 后作**表语** | `This is how…` / `That's why…` | That's **why** I quit.（表语） |
| -ever 系列 | 名词 **或** 让步状语 | 见第三章 | **Wherever** you go, I follow.（让步状语） |

🔑 看到融合词别慌：心里换成 **the X that**，是名词还是状语立刻清楚。

## 五、两条边界：再排除两个易混对象

### 5.1 vs 带先行词的普通关系词：先行词在不在"词外面"？

```
普通关系词（先行词明摆在前面）：
   I know the place that you mean.   ← 先行词 the place 在 that 外面

融合关系词（先行词被吞进词里，外面是空的）：
   I know where you mean.            ← 前面没有先行词，where 自带
```
🔑 **找得到外置先行词** → 用 that/which 等普通关系词；**找不到、又要引导名词从句** → 用融合词。

> [!WARNING]
> ### 铁律：先行词已被吞掉，别在外面再挂一个同义词
> ```
> ❌ the way how I did it      （way 和 how 重复，二选一）
> ✅ the way I did it   /   ✅ how I did it
> ```
> `how` 已经 = the way，再写 `the way how` 等于把"way"说两遍。要么裸先行词 + 普通关系词，要么用融合词，**不能既要又要**。

### 5.2 vs 间接疑问句：两者都不倒装，差在"那坨"是**东西**还是**问题/答案**

注意：间接疑问句（`I wonder where he went`）**也不倒装**，所以第一章的"倒装刀"切不开它俩。它俩的区别在**语义**：

```
I don't know what he wants.
融合关系（= the thing that）：我不知道"他想要的那个东西"     ← 指向一个具体的物
间接疑问（= 对"他要什么"这个问题的答案）：我不知道"他想要什么"  ← 指向一个待解的问题
```
🔑 能顺畅换成 **"the X that…"**、指向一个具体东西 → 偏**融合词**；本质是"……这个问题/答案"（常见于 wonder/ask/whether 语境）→ 偏**间接疑问**。两者结构相同（都是名词性从句、都不倒装），很多句子两种读法都通，不必死抠。

- [ ] `Whoever broke it must pay` 里 `whoever` = ____？整坨在句中当什么成分？
- [ ] 为什么本篇不讲"还原/回溯"，而《特殊疑问句手册》要讲？
- [ ] 同样引导名词从句，什么时候用 `where`，什么时候用 `the place that`？

<details>
<summary>点开看推导（看"为什么"）</summary>

1. 融合词从句**不倒装、不借 do**（第 1.2 条）；`where does she live` 是把疑问句的倒装错装进来了。根本区别：疑问词发问要倒装，融合词打包不倒装。
2. whoever = anyone who / the person who；整坨打包成**名词**，作全句**主语**。
3. 因为"回溯/还原"是给**倒装过的语序复位**；融合词压根没倒装，没有语序可复位（第 1.3 条），理解它只需"替换成 the X that"。
4. 找不到外置先行词、要引导名词从句 → 融合词 `where`；句子里已摆出先行词 `the place` → 普通关系词 `the place (that/where)`。依据：先行词在不在词外面（第 5.1 条）。

</details>
