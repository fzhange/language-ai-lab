# 英语不规则动词完全理解手册

> **写给谁看**：被 `lost / stuck / drove / written` 这种"奇怪变形"困扰过的人
>
> **核心思路**：不规则动词不是"乱来"，而是英语最古老的化石 —— 抓住「**变形模式**」和「**核心画面**」，就能一次性吃掉一整族词。

---

## 一、单词收录

> [!TIP]
> 每个词遵循统一结构：**形态 → 变化逻辑 → 核心画面 → 多义衍生 → 易混点**

---

### 1. `lose` / `lost` / `lost`（失去）

#### 📐 形态

| 形式 | 拼写 | 发音 |
|---|---|---|
| 原形 | lose | /luːz/（**z** 音，有声） |
| 过去式 | lost | /lɒst/（**s** 音，无声） |
| 过去分词 | lost | /lɒst/ |
| 现在分词 | losing | /ˈluːzɪŋ/ |

#### 🔄 变化逻辑

```
lo[se] → lo[st]
   ↑       ↑
  软软的  硬硬的
  /z/    /st/
```

⚠️ **注意**：这不是"内部元音变化"，而是**词尾辅音的变化**（se → st）。是英语里少见的特殊变形，记住一个就好。

📌 **发音陷阱**：
- `lose` 的 `s` 读 **/z/**（嗡嗡声，浊音）
- `lost` 的 `s` 读 **/s/**（嘶嘶声，清音）
- 中国人最容易把 `lose` 念成 /luːs/ —— **错！** 那是 `loose`（松的），完全是另一个词。

#### 🎬 核心画面

```
"东西从你手中溜走 / 离开你 / 不见了"
                ↓
       任何"从有变没"的过程，都是 lose
```

#### 🌳 多义衍生：抓住"失去"画面，全部秒懂

| 搭配 | 字面 | 实际含义 |
|---|---|---|
| lose money | 失去钱 | 亏钱、输钱 |
| lose a game | 失去比赛 | 输了比赛 |
| lose weight | 失去体重 | 减肥 |
| lose patience | 失去耐心 | 不耐烦了 |
| lose temper | 失去脾气控制 | 发火 |
| lose face | 失去脸 | 丢脸（中英完全一致！） |
| lose touch | 失去联系 | 失联 |
| lose your way | 失去路 | 迷路 |
| lose your mind | 失去心智 | 疯了 |
| lose interest | 失去兴趣 | 没兴趣了 |
| **be lost** | **处于"失去"的状态** | **迷路了 / 茫然 / 想不通** |
| **get lost** | **变成"失去"的状态** | **迷路了**（也可作粗鲁的"滚开"） |

#### ⚠️ 致命易混：`lose` vs `loose` vs `loss`

这三个词是中国人**最常出错的一组**，必须一次分清：

| 词 | 词性 | 发音 | 含义 | 记忆 |
|---|---|---|---|---|
| `lose` | **动词** | /luːz/ | 失去 | 一个 o，结尾 /z/ |
| `loose` | **形容词** | /luːs/ | 松的、宽松的 | 两个 o，结尾 /s/ |
| `loss` | **名词** | /lɒs/ | 损失 | lose 的名词形 |

🧠 **画面记忆法**：
- `loose` 多一个 `o` → 像两个圈圈散开 → **松松垮垮**
- `lose` 少一个 `o` → 紧凑、丢了一个 o → **失去**

> *My pants are **loose** because I've **lost** weight. → That's a great **loss** of fabric.*  
> *我裤子**松了**因为我**减重了**，布料真是个巨大**损失**。*

### 2. `stick` / `stuck` / `stuck`（扎/粘/卡）

#### 📐 形态

| 形式 | 拼写 | 发音 |
|---|---|---|
| 原形 | stick | /stɪk/ |
| 过去式 | stuck | /stʌk/ |
| 过去分词 | stuck | /stʌk/ |
| 现在分词 | sticking | /ˈstɪkɪŋ/ |

#### 🔄 变化逻辑（i → u → u）

```
st[i]ck → st[u]ck → st[u]ck
   ↑         ↑         ↑
  /ɪ/       /ʌ/       /ʌ/
```

📌 **同族兄弟**（一次记一窝）：

| 现在 | 过去 | 分词 |
|---|---|---|
| dig | dug | dug |
| sting | stung | stung |
| swing | swung | swung |
| strike | struck | struck |
| sneak | snuck | snuck（美式口语） |

🔑 看到 `i → u` 模式，就知道是**这一族**。

#### 🎬 核心画面：颠覆认知

> ⚠️ 大多数人以为 `stick` 的本义是"棍子"。**错。**

历史顺序是**反过来**的：

```
最古老的根：*steig-（印欧语）= "扎、刺、戳"
             ↓
   ① 动词：stick = 扎
             ↓
   ② 名词：stick = "用来扎的那个东西" = 棍子
```

类比中文：「钩子」之所以叫钩子，是因为它能"钩"东西。  
英语里 `stick` 也是同款逻辑 —— **棍子 = "扎子"**。

#### 🌳 多义衍生：从"扎"长出整棵树

```
① 扎、刺 (pierce)
       ↓ 扎进去之后？
② 插入、粘住 (attach)
       ↓ 粘住之后？
③ 卡住、动不了 (be unable to move)
       ↓ 引申到抽象层面
④ 坚持、不放弃 (persist)
```

| 搭配 | 含义 |
|---|---|
| stick a needle in | 把针**扎**进去 |
| stick a stamp on | 把邮票**贴**在…上 |
| be stuck in traffic | **堵**在路上 |
| be stuck on a problem | **卡**在一道题上 |
| be stuck with sb/sth | 被**赖**上某人/某物（甩不掉） |
| stick to | **坚持**、不偏离 |
| stick around | **待**在附近别走 |
| stick out | **突出**、显眼 |
| stick up for sb | 为某人**挺身**而出 |
| stick it out | **熬**过去、坚持到底 |

#### 🔍 衍生词族（一次吃光）

| 词 | 拆解 | 含义 |
|---|---|---|
| `sticker` | 扎/粘的小东西 | 贴纸 |
| `sticky` | 充满"粘"的性质 | 黏的（手 sticky / 局面 sticky=棘手） |
| `stuck-up` | 卡得太"高" | 自命不凡（鼻子翘得拔不下来） |
| `stickler` | 一直"扎"着不放的人 | 死磕规矩的人 |

#### ⚠️ 易错点

❌ `sticked`（不存在，写出来就是错的）  
✅ `stuck`（永远用这个）

> 唯一例外：在棍球类运动里描述"用球棍打"，可见 `sticked`，**日常忽略**。

#### 🎯 实战训练

遇到"**走不了 / 换不掉 / 脱不开 / 卡住了**"的场景，立刻反应 `be stuck`：

| 中文 | 英文 |
|---|---|
| 我被困在电梯里了 | I'm **stuck** in the elevator. |
| 这首歌一直在我脑子里循环 | This song is **stuck** in my head. |
| 拉链卡住了 | The zipper is **stuck**. |
| 我感冒了只能在家待着 | I'm **stuck** at home with a cold. |
| 这个老板烂透了，但我没办法换 | I'm **stuck** with this terrible boss. |

### 3. `strike` / `struck` / `struck`（击/敲/突然作用）

#### 📐 形态

| 形式 | 拼写 | 发音 |
|---|---|---|
| 原形 | strike | /straɪk/ |
| 过去式 | struck | /strʌk/ |
| 过去分词 | struck（也可作 stricken，多用作形容词） | /strʌk/, /ˈstrɪkən/ |
| 现在分词 | striking | /ˈstraɪkɪŋ/ |

#### 🔄 变化逻辑（i → u → u）

跟 `stick` / `dig` / `sting` 是**同一族兄弟**：

```
str[i]ke → str[u]ck → str[u]ck
   ↑          ↑          ↑
  /aɪ/       /ʌ/        /ʌ/
```

📌 注意元音的"力度变化"：`/aɪ/`（双元音、张开）→ `/ʌ/`（短促、收紧）—— 像**挥剑出去再瞬间收回**的物理动作。

#### 🎬 核心画面：**「挥 → 接触」之间那一道闪光的瞬间**

⚠️ 这是 `strike` 最容易被误解的地方 —— 它**不是**"挥的过程"，**也不是**"击中后的结果"，而是**两者之间那一刹那的接触点**：

```
       挥 ─────────► ★ ─────────► 击中后的状态
      （过程）      （瞬间）       （结果）
       swing        STRIKE          aftermath
```

> 🎯 **`strike` 锁定的，是中间那个「★ 接触瞬间」—— 一道闪光、一记落点、一个决定性的瞬间。**  
> 它包含挥的力度、也包含击中的那一刻，**但不延伸到击中之后**。

##### 用对比词区分，秒懂

| 词 | 锁定的部分 | 画面 |
|---|---|---|
| **swing** | 「挥」的**过程** | 看到剑在空中划弧 |
| **strike** ⭐ | 「挥 → 接触」的**瞬间** | 看到剑**砍中**那一刹那的闪光 |
| **hit** | 「接触」**本身** | 强调"打到了"这个事实 |
| **bruise / wound** | 击中**之后**的结果 | 看到伤口、淤青 |

```
swing ──── STRIKE ──── hit ──── bruise
 过程       瞬间       事实      结果
```

##### 用例句反推，验证「瞬间」本质

| 例句 | 锁定的"那一瞬"是什么 |
|---|---|
| Lightning **struck** the tree. | 闪电**触到树的那一道光** |
| The clock **strikes** twelve. | 钟锤**敲到铜钟的那一记响** |
| It **struck** me that... | 想法**击中大脑的那一刻** |
| I was **struck** by her beauty. | 美貌**撞进我眼里的那一瞬** |
| Disaster **struck**. | 灾难**落地的那一刻** |
| **strike** a match | 火柴**擦过纸盒的那一闪** |
| **strike** a deal | 双方**击掌成交的那一刻** |
| **strike** gold | 铲子**碰到金子的那一刻** |

🔑 **共同点**：全都是**「★ 瞬间」**——没有一个是过程，也没有一个是结果。  
这就是为什么 `strike` 永远带着一种**「决定性」和「突发感」**——因为它本身就锁定在那一闪。

##### 为什么这个区分如此重要？

理解这一点，就解开了 `strike` 最玄学的两个用法：

```
"It struck me that..." 
       ↑
   不是"我慢慢想到"（过程），
   不是"我深思熟虑后认为"（结果），
   而是"想法'啪'地一下撞进脑子"（瞬间）

"She struck me as honest."
       ↑
   第一印象 = 那种「瞬间形成」的判断
   完美对应 strike 的"瞬间"本质
```

#### 🌳 多义衍生：从「★ 接触瞬间」长出的整片森林

> ⚠️ **不要分开记 8 个意思**，记**一个瞬间**："**★ 挥到接触的那一刹那**"。区别只在于"谁在挥、击中了什么"。

##### ① 物理击打（最直接）

```
strike = 挥手/挥物 → 击中目标
```

| 搭配 | 含义 |
|---|---|
| strike sb on the head | **打**某人的头 |
| The clock **strikes** twelve | 钟**敲**十二下 |
| Lightning **struck** the tree | 闪电**击中**树 |

##### ② 突然作用于... （灾难、情感"袭来"）

★ 瞬间接触的对象不是身体，而是**抽象状态** —— 命运/情绪在某一刻"砸"中你：

| 搭配 | 含义 |
|---|---|
| Disaster **struck**. | 灾难**降临** |
| Fear **struck** him. | 恐惧**袭来** |
| An idea **struck** me. | 灵感**击中**我 |

##### ③ 触动印象（"打中"你的认知）

★ 瞬间接触的目标是**你的脑子/心** —— 第一印象、灵光一现：

| 搭配 | 含义 |
|---|---|
| It **strikes** me that... | 我**突然觉得**…… |
| She **strikes** me as honest. | 她给我的印象是诚实 |
| I was **struck** by her beauty. | 我**被**她的美**打动** |

##### ④ 擦出 / 划着（轻擦表面的"瞬间接触"）

★ 接触轻一点、擦着表面 —— 就是"划"：

| 搭配 | 含义 |
|---|---|
| strike a match | **划**火柴 |
| strike a chord | **拨动**心弦（=戳中共鸣） |

##### ⑤ 敲定 / 达成（双方"击掌"成交）⭐

古代敲定交易要**击掌、敲钟、敲桌**，所以 `strike` = 达成：

| 搭配 | 含义 |
|---|---|
| strike a deal | **达成**协议 |
| strike a bargain | **谈成**交易 |
| strike a balance | **找到**平衡 |

##### ⑥ 罢工（劳工"一击" / 放下工具的决断）⭐

历史来源：1768 年伦敦海员把船帆"strike down"（放下），停工抗议 → 后来引申为**集体停工**这一"决断的一击"：

| 搭配 | 含义 |
|---|---|
| go on **strike** | 去**罢工** |
| be on **strike** | 处于罢工状态 |
| call a **strike** | 号召罢工 |

##### ⑦ 棒球术语：好球（投手投出的一记"决定性接触"）⭐

棒球里的 `strike` = 投手投出的"**应被打到的好球**"（即位于打击带内、构成一次有效"接触机会"的投球）。打者三次没打中 → `strike out`：

| 搭配 | 含义 |
|---|---|
| Strike one! | **一击**（一个 strike） |
| **strike out** | 三振出局 → 引申"**彻底失败**" |
| Three strikes and you're out. | 三振出局（= 第三次警告就完蛋） |

##### ⑧ 挖到 / 找到（挖掘工具"击中"宝藏）

| 搭配 | 含义 |
|---|---|
| strike gold | **挖到**金子 → 大获成功 |
| strike oil | **挖到**石油 |
| strike it rich | **突然发财** |

#### 🎯 罢工 vs 好球 —— 两个最让人困惑的意思怎么统一？

中国人最懵的就是这两个意思看似毫无关系。但在**「★ 决定性接触瞬间」**画面下，逻辑完美自洽：

```
       核心画面：一记决断的「★ 接触瞬间」
                    ↓
       ┌────────────────────────────┐
       ↓                            ↓
   工人对老板的"一击"          投手对打者的"一击"
   ＝ 罢工                      ＝ 好球（strike）
   ＝ 集体决断的停工            ＝ 强势投出的可击之球
```

> 🔑 **共同点**：都是"**有意发出的、决断性的一击**"——锁定的都是那个**接触瞬间**，不同的只是"谁挥、击中谁"。

#### 🔍 衍生词族（一次吃光）

| 词 | 拆解 | 含义 |
|---|---|---|
| `striking` | "挥击的、击中眼球的" | **显著的、惊人的**（引人注目 = 一记打中你眼球） |
| `stricken` | "被击中的" | **罹患的、重创的**（古老分词形，多作形容词） |
| `striker` | "挥击的人" | 罢工者；足球**前锋**（专门"出击"的人） |
| `strikeout` | "挥出去" | 三振出局；引申"失败" |
| `unstruck` | "未被击中的" | 未受影响的 |

##### `stricken` 的特殊用法（高频考点）

`stricken` 现代几乎只作**形容词**用，表示"**被…重创的**"，常构成复合词：

| 搭配 | 含义 |
|---|---|
| poverty-stricken | 被贫困击中 → **贫困潦倒的** |
| grief-stricken | 被悲伤击中 → **悲痛欲绝的** |
| panic-stricken | 被恐慌击中 → **惊慌失措的** |
| disaster-stricken | 被灾难击中 → **受灾的** |
| awe-stricken | 被敬畏击中 → **肃然起敬的** |

⚠️ **别用错**：完成时态用 `struck`（I have **struck** a deal），不要用 `stricken`。

#### ⚠️ 易错点

| ❌ 错 | ✅ 对 | 说明 |
|---|---|---|
| I have stricken a deal. | I have **struck** a deal. | 完成时用 struck，不用 stricken |
| poverty-struck | poverty-**stricken** | 复合形容词必须用 stricken |
| The clock striked. | The clock **struck**. | 不规则动词，没有 striked |

#### 🎯 实战训练

任何时候你想表达"**一记决断性的动作 / 突然击中**"，都可以试试 `strike`：

| 中文 | 英文 |
|---|---|
| 我突然意识到自己错了 | It **struck** me that I was wrong. |
| 这部电影给我留下深刻印象 | The movie really **struck** me. |
| 我们达成了一个不错的协议 | We **struck** a good deal. |
| 工人们罢工了 | The workers went on **strike**. |
| 他被这场悲剧重创 | He was **stricken** by the tragedy. |
| 这首歌触动了我的心弦 | The song **struck** a chord with me. |
| 你创业了？真厉害 | You **struck out** on your own? Impressive. |

> 🎬 **一句话记忆**：`strike` 不是 8 个意思，是**一个动作（挥击）打在 8 种东西上**。

### 4. `fall` / `fell` / `fallen`（落下）

#### 📐 形态

| 形式 | 拼写 | 发音 |
|---|---|---|
| 原形 | fall | /fɔːl/ |
| 过去式 | fell | /fel/ |
| 过去分词 | fallen | /ˈfɔːlən/ |
| 现在分词 | falling | /ˈfɔːlɪŋ/ |

#### 🔄 变化逻辑（a → e → a，但分词多个 -en 尾巴）

```
f[a]ll → f[e]ll → f[a]llen
  ↑        ↑         ↑
 /ɔː/     /e/      /ɔː/ + en
```

📌 **同族兄弟**（元音换 + 分词加 `-en`，一窝端走）：

| 现在 | 过去 | 分词 |
|---|---|---|
| fall | fell | fallen |
| eat | ate | eaten |
| take | took | taken |
| shake | shook | shaken |
| break | broke | broken |

🔑 看到「过去式换元音、分词再补一个 `-en`」，就知道是**这一族**。
⚠️ **别混**：`fall`（落，不及物）≠ `fell`（砍倒，规则动词 fell-felled-felled）。后者是另一个独立的词，正好长得像 `fall` 的过去式。

#### 🎬 核心画面：**「高 → 低」之间那一段自由下坠的过程**

⚠️ `fall` 锁定的**不是**起点（在高处），**也不是**终点（已落地），而是**两点之间那段「失去支撑、被重力拽下去」的下坠过程**：

```
   在高处 ─────────► ★ 下坠 ─────────► 落地/停在低处
   （起点）         （fall）            （结果）
   stand/be up      FALL               land/be down
```

> 🎯 **`fall` 锁定的，是「从高到低、失去支撑」的那段下落。**
> 它不需要谁去推、去扔 —— **重力自己干活**，这是它和 `drop`（主动松手）、`throw`（主动抛）最大的区别。

##### 用对比词区分，秒懂

| 词 | 锁定的部分 | 画面 |
|---|---|---|
| **drop** | 主动「松手」让它掉 | 你手一松，杯子掉了（有施动者） |
| **fall** ⭐ | 自己「失去支撑」往下走 | 没人碰它，它自己倒/落（无施动者） |
| **land** | 落地「那一刻」 | 强调接触地面的结果 |

```
stand ──── FALL ──── land ──── lie there
站着       下坠       落地        躺在那
```

##### 用例句反推，验证「失去支撑往下走」本质

| 例句 | 锁定的"下坠"是什么 |
|---|---|
| Leaves **fall** in autumn. | 叶子**离开枝头往下飘** |
| He **fell** off the ladder. | 身体**失去支撑摔下来** |
| Prices **fell** sharply. | 价格**数字往下掉** |
| She **fell** asleep. | 意识**从清醒"沉"入睡眠** |
| He **fell** in love. | 人**"陷"进爱里**（控制不住地往下） |
| The city **fell** to the enemy. | 城市**从"挺立"塌向陷落** |
| Night **falls**. | 夜色**降临、压下来** |

🔑 **共同点**：全都是**「从某状态失去支撑、不由自主地往下/往里走」**——没有一个是主动用力的，都是**"被牵引着下去"**。这就是为什么 `fall` 总带一种**「不受控、自然发生」**的味道。

#### 🌳 多义衍生：从「失去支撑往下走」长出的整片森林

> ⚠️ **不要分开记一堆意思**，记**一个画面**："**失去支撑，不由自主往下/往里走**"。区别只在于"什么在下落、落进什么"。

##### ① 物理下落（最直接）

| 搭配 | 含义 |
|---|---|
| fall down | **摔倒**、倒下 |
| fall off | 从…上**掉下来** |
| The rain **falls** | 雨**落**下 |

##### ② 数值/程度下降（数字"往下走"）

★ 下落的对象是抽象的数值 —— 价格、温度、数量"往下掉"：

| 搭配 | 含义 |
|---|---|
| Prices **fall**. | 价格**下跌** |
| Temperature **falls**. | 气温**下降** |
| Demand **fell**. | 需求**减少** |

> 💡 雅思 Task 1 折线图描述「下降」的核心动词就是 `fall`（同义：drop / decline / decrease）。

##### ③ 陷入某状态（"沉/陷"进一种状态）

★ 失去对自己状态的控制，不由自主"掉进"某种状态：

| 搭配 | 含义 |
|---|---|
| fall asleep | **入睡**（沉进睡眠） |
| fall ill / sick | **病倒** |
| fall silent | **陷入沉默** |
| fall in love | **坠入**爱河 |
| fall into a trap | **掉进**陷阱 |

##### ④ 沦陷 / 垮台（"挺立"塌向"陷落"）

★ 从"屹立"的状态崩塌下来：

| 搭配 | 含义 |
|---|---|
| The city **fell**. | 城市**沦陷** |
| The government **fell**. | 政府**垮台** |
| The empire **fell**. | 帝国**衰亡** |

##### ⑤ 降临 / 来临（时间、夜色"落"下来）

★ 时间节点像东西一样"落"到我们头上：

| 搭配 | 含义 |
|---|---|
| Night **falls**. | 夜幕**降临** |
| Silence **fell**. | 寂静**笼罩**下来 |
| Christmas **falls** on a Monday. | 圣诞节正好**落在**周一 |

#### 🔍 衍生词族（一次吃光）

| 词 | 拆解 | 含义 |
|---|---|---|
| `fall`（名词） | "下落"这件事 | 摔落；**秋天**（美式 = 叶落之季）；瀑布（**waterfall** = 水落） |
| `fallen` | "已落下的" | 堕落的、阵亡的（the fallen = 阵亡将士） |
| `fallout` | "落下来的东西" | 核辐射尘；引申**后果、余波** |
| `pitfall` | "坑 + 落" | 隐患、陷阱（会让你掉进去的坑） |
| `downfall` | "向下 + 落" | 垮台、衰败的原因 |
| `shortfall` | "短 + 落" | 缺口、不足额 |

#### ⚠️ 易错点

| ❌ 错 | ✅ 对 | 说明 |
|---|---|---|
| He falled down. | He **fell** down. | 不规则动词，没有 falled |
| I have fell asleep. | I have **fallen** asleep. | 完成时用 fallen，不用 fell |
| The tree was fell. | The tree **fell** / was **felled**. | fall（自己倒）vs fell（被砍倒），别混 |
| fall the cup | **drop** the cup | fall 不及物，"扔/松手让某物掉"用 drop |

#### 🎯 实战训练

任何"**失去支撑、不由自主往下/往里走**"的场景，都可以试试 `fall`：

| 中文 | 英文 |
|---|---|
| 我从自行车上摔下来了 | I **fell** off my bike. |
| 我一上车就睡着了 | I **fell** asleep as soon as I got on. |
| 上个月房价下跌了 | House prices **fell** last month. |
| 他疯狂地爱上了她 | He **fell** madly in love with her. |
| 整座城市陷入沉默 | The whole city **fell** silent. |
| 这是创业最常见的陷阱 | This is the most common **pitfall** of startups. |

> 🎬 **一句话记忆**：`fall` 不是"摔倒"一个意思，是**"失去支撑、被牵引着往下走"这一个画面，落在物体、数字、状态、时间各种东西上**。

### 5. `choose` / `chose` / `chosen`（选择）

#### 📐 形态

| 形式 | 拼写 | 发音 |
|---|---|---|
| 原形 | choose | /tʃuːz/（**oo** 长音 + 结尾 **/z/** 浊音） |
| 过去式 | chose | /tʃəʊz/ |
| 过去分词 | chosen | /ˈtʃəʊzən/ |
| 现在分词 | choosing | /ˈtʃuːzɪŋ/ |

#### 🔄 变化逻辑（元音换 + 分词补 `-en`）

```
ch[oo]se → ch[o]se → ch[o]sen
   ↑          ↑          ↑
  /uː/       /əʊ/      /əʊ/ + en
```

📌 **同族兄弟**（过去式换元音、分词再补一个 `-en`，和 `fall` 同一大族的"-en 帮"）：

| 现在 | 过去 | 分词 |
|---|---|---|
| choose | chose | chosen |
| break | broke | broken |
| speak | spoke | spoken |
| freeze | froze | frozen |
| steal | stole | stolen |
| wake | woke | woken |

🔑 看到「过去式 `-o-`、分词再加 `-en`」，就知道是**这一族**。`choose` 只是多了开头那对 `oo` 被压缩成 `o`。

📌 **发音陷阱**：
- `choose`（动词）结尾是 **/z/**（嗡嗡声，浊音）
- `choice`（名词）结尾是 **/s/**（嘶嘶声，清音）—— 别把动词念成 /tʃuːs/。

#### 🎬 核心画面：**「锁定一个 ＝ 同时放弃其余」的那一下取舍**

> ⚠️ 大多数人以为 `choose` 就是"挑、拿"。**只对了一半。**

`choose` 的灵魂**不在"拿起哪个"，而在"放下哪些"**。它锁定的是**多个选项并存时，拎出其中一个、其余全部排除**的那个取舍瞬间：

```
   A B C D 并排摆着 ───► ★ 拎出一个 ───► 其余全部放下
   （多选项并存）        （CHOOSE）        （承担 + 放弃）
```

> 🎯 **`choose` 锁定的，是「在多个之间做取舍」这件事 —— 没有"多个选项"，就没有 `choose`。**
> 这也是它和 `pick`（随手拿）最大的区别：`choose` 永远暗含**比较 + 排除**。

##### 用对比词区分，秒懂

| 词 | 锁定的部分 | 画面 |
|---|---|---|
| **pick** | 随手「拿起」一个 | 不一定权衡，伸手就拿（pick a card） |
| **choose** ⭐ | 比较后「挑定」一个 | 看了一圈，**取此舍彼**（含判断、含放弃） |
| **select** | 从一组里「精选」 | 更正式、更挑剔（select candidates） |
| **decide** | 心里「拍板」的终点 | 不强调有几个实物选项，强调下了决心 |

```
pick ──── CHOOSE ──── decide
随手拿     取此舍彼     心里拍板
```

##### 用例句反推，验证「取舍」本质

| 例句 | 锁定的"取舍"是什么 |
|---|---|
| **Choose** a career. | 从多条人生路里挑一条，**其余都放弃** |
| **choose between** two jobs | `between` 直接点破"**二选一**" |
| She **chose** to stay. | 在"走 / 留"之间**锁定"留"、排除"走"** |
| the **chosen** one | 从众人中**被挑出来的那一个** |
| You can't have both — **choose**! | "鱼与熊掌"——**取舍**本质暴露无遗 |

🔑 **共同点**：每一个都站在**「多个并存 → 取一舍余」**的同一位置。只要句子里没有"可放弃的其余"，那个动作就不该是 `choose`，而是 `pick` 或 `take`。

#### 🌳 多义衍生：从「取舍」长出的几根枝

> ⚠️ `choose` 不像 `strike` 那样开枝散叶，它**始终咬住"取舍"这一个点**，变的只是"在什么之间选、选去做什么"。

##### ① 在选项之间挑（最直接）

| 搭配 | 含义 |
|---|---|
| choose a gift | **挑**一份礼物 |
| choose between A and B | 在 A、B 之间**二选一** |
| choose from a list | 从清单里**选** |

##### ② 选择"去做某事"（在"做 / 不做"之间取舍）

★ 选项变成抽象的"行动"——做还是不做，也是一种取舍：

| 搭配 | 含义 |
|---|---|
| choose **to** do sth | **选择**去做某事 |
| She chose to leave. | 她**选择**离开 |

> ⚠️ 固定接 `to do`：✅ choose **to** stay　❌ choose staying。

#### 🔍 衍生词族（一次吃光）

| 词 | 拆解 | 含义 |
|---|---|---|
| `choice` | "choose 这件事"的名词形 | 选择；选项；（形容词）精选的（**first choice** = 首选） |
| `choosy` | 充满"挑"的性质 | **挑剔的**（=老在取舍，难伺候） |
| `chosen` | "已被挑出的" | 被选中的、天选的（**the chosen one** = 天选之人） |

#### ⚠️ 致命易混：`choose` vs `chose` vs `choice`

中国人**最常出错的一组**，一次分清：

| 词 | 身份 | 发音 | 记忆 |
|---|---|---|---|
| `choose` | **动词·原形** | /tʃuːz/ | 双 `o`，结尾 /z/，"正在做" |
| `chose` | **动词·过去式** | /tʃəʊz/ | 单 `o`，已经选完了 |
| `choice` | **名词** | /tʃɔɪs/ | 结尾 /s/，"选择"这个东西 |

🧠 **记忆法**：`choose` 多一个 `o` → 像两只眼睛**还在左右挑** → 进行中的动作；`chose` 少一个 `o` → 挑完了，收一只眼。

#### ⚠️ 易错点

| ❌ 错 | ✅ 对 | 说明 |
|---|---|---|
| He choosed it. | He **chose** it. | 不规则动词，没有 choosed |
| I have chose. | I have **chosen**. | 完成时用 chosen，不用 chose |
| choose staying | choose **to** stay | 接 to do，不接 doing |
| Make a good choose. | Make a good **choice**. | "做选择"用名词 choice |

#### 🎯 实战训练

任何"**在多个之间取此舍彼**"的场景，都可以试试 `choose`：

| 中文 | 英文 |
|---|---|
| 我在两份工作之间难以抉择 | I can't **choose** between the two jobs. |
| 她选择了相信他 | She **chose** to trust him. |
| 你被选中了 | You've been **chosen**. |
| 别这么挑剔 | Don't be so **choosy**. |
| 这是我的首选 | This is my first **choice**. |

> 🎬 **一句话记忆**：`choose` 不是"挑"那么简单，是**"锁定一个、同时放弃其余"这一下取舍**——没有可舍的选项，就不是 choose。
