## ⚠️ 关键一招：词性不看后缀，看它在句子里站的"坑"

你会撞到一个让人头大的现象——**同一个后缀对应好几种词性**：

|  | 动词 | 形容词 | 名词 |
|:---:|:---|:---|:---|
| `-ate` | activ**ate** | accur**ate** | gradu**ate** |
| `-al` | — | natur**al** | arriv**al** |
| `-en` | wid**en** | wood**en** | — |

## 🔄 词的变形：一个词如何变出"一家子"

很多人问：**digest 已经是个完整的词了，为什么还要加后缀？**

答案很简单：**因为你想换一种说法。**

---

### 🔑 本质区别：英语是"强类型"，中文是"弱类型"

> 💡 **程序员秒懂**：英语像 TypeScript，中文像 JavaScript！

#### 🔷 英语 = 强类型语言（Strong Typing）

像 Java、TypeScript 一样，英语**必须显式声明词性**：

```
digest (动词) → digestion (名词) → digestive (形容词) → digestible (形容词)
```

- 每个词**必须携带后缀**来声明它的"类型"（词性）
- 你**不能**在需要名词的地方直接用动词，必须先转换
- "类型"**写在词本身**，一眼就能看出来

#### 🔶 中文 = 弱类型语言（Weak Typing）

像 JavaScript、Python 一样，中文允许**隐式类型转换**：

```
消化 = 动词 / 名词 / 形容词（上下文决定）
```

- **同一个词**可以充当不同词性
- **上下文**决定"类型"，而不是词的形式
- 不需要显式"后缀"来转换

---

#### 📊 对比表

| 特性 | 英语（强类型） | 中文（弱类型） |
|:---|:---|:---|
| 类型声明 | 显式（必须加后缀） | 隐式（上下文决定） |
| "消化食物" | **digest** food（动词形式） | 消化 |
| "消化不好" | **digestion** is bad（名词形式） | 消化 |
| "消化系统" | **digestive** system（形容词形式） | 消化 |
| 类型可见？ | ✅ 是，看词尾就知道 | ❌ 否，需要看上下文 |

---

#### 💻 代码类比（程序员专属）

```javascript
// 中文（弱类型）- 同一个"变量"到处能用
let 消化 = "digest";
用作名词(消化);      // ✅ 直接用
用作动词(消化);      // ✅ 直接用
用作形容词(消化);    // ✅ 直接用

// 英语（强类型）- 必须显式转换
let digest = "digest";
用作名词(digest + "ion");      // digestion ✅
用作动词(digest);              // digest ✅
用作形容词(digest + "ive");    // digestive ✅
```

---

#### 🎯 这就是后缀难的原因！

> 对于中国人来说，你从来不需要"声明类型"——同一个词到处都能用。
>
> 但在英语里，你**必须**加上正确的后缀来"类型转换"！

**把后缀想象成"类型转换操作符"**：

| 操作 | 后缀 | 例子 |
|:---|:---|:---|
| `(Type)Noun` | `-tion`, `-ment`, `-ness` | digest → diges**tion** |
| `(Type)Adjective` | `-ive`, `-ful`, `-ous` | digest → digest**ive** |
| `(Type)Verb` | `-ize`, `-ify`, `-en` | modern → modern**ize** |
| `(Type)Adverb` | `-ly` | quick → quick**ly** |

### digest 一家子

| 你想表达 | 英语怎么说 | 用在哪里 |
|----------|------------|----------|
| 消化（动作） | **digest** | I **digest** food. 我消化食物 |
| 摘要（东西） | **digest** | a news **digest** 新闻摘要 |
| 消化（这件事/过程） | **digestion** | My **digestion** is bad. 我的消化不好 |
| 消化的（形容词） | **digestive** | **digestive** system 消化系统 |
| 可消化的（能被消化） | **digestible** | easily **digestible** food 容易消化的食物 |

看到了吗？同一个核心意思"消化"，加不同后缀就能换不同说法。

##### 公式 1：形容词 → 名词（把"状态"变成"概念"）

| 后缀 | 语义逻辑 | 你在问什么问题？ | 怎么判断用哪个？ |
|:---|:---|:---|:---|
| `-ness` | 状态的感受 | "这种状态感觉如何？" | **短词、常见词**用这个 |
| `-ity/-ty` | 把特质变成"东西" | "这个特质本身叫什么？" | **长词、学术词**用这个 |
| `-cy` | `-ity` 的变体 | 同上（把特质变成名词） | 形容词以 **-ant/-ent/-ate** 结尾 |
| `-th` | 状态的测量值 | "能量化吗？多少？" | **可测量**的基础词（长宽高深） |
| `-dom` | 状态的领域/范围 | "这种状态的地盘是什么？" | 表示"领域/王国" |
| `-hood` | 状态的时期/群体 | "这种状态持续多久/包括谁？" | 表示"人生阶段/社区" |
| `-ship` | 状态的关系/身份 | "这种状态涉及什么关系？" | 表示"关系/身份" |

**🔍 深入理解 `-ity/-ty`：让形容词可以独立存在**

`-ity` 的核心逻辑：**形容词只能依附别人（"real story"），加了 `-ity` 就能自己站住（"reality"）**。

| 形容词 | 问题 | + `-ity` | 变成了什么 |
|:---|:---|:---|:---|
| **real**（真实的） | "真实"这个特质叫什么？ | real**ity** | 现实/真实性 |
| **able**（有能力的） | "有能力"这个特质叫什么？ | abil**ity** | 能力 |
| **possible**（可能的） | "可能"这个特质叫什么？ | possibil**ity** | 可能性 |
| **creative**（有创造力的） | "有创造力"这个特质叫什么？ | creativ**ity** | 创造力 |
| **curious**（好奇的） | "好奇"这个特质叫什么？ | curios**ity** | 好奇心 |

**类比理解**：
- 形容词 **real** 只能修饰别的东西："a real story"（一个真实的故事）
- 名词 **reality** 可以独立存在："Reality is harsh"（现实是残酷的）

`-ity` 就是让形容词"独立"出来，变成可以单独讨论的概念。

**🔍 深入理解 `-cy`：其实就是 `-ity` 的"搭配变体"**

`-cy` 和 `-ity` 功能相同，都是把形容词变成名词。区别只是**形态搭配**：

> 当形容词以 **-ant / -ent / -ate** 结尾时，用 `-cy` 而不是 `-ity`

| 形容词 | 结尾 | + `-cy` | 含义 |
|:---|:---|:---|:---|
| **vacant**（空着的） | -ant | vacan**cy** | 空缺 |
| **relevant**（相关的） | -ant | relevan**cy** | 相关性 |
| **pregnant**（怀孕的） | -ant | pregnan**cy** | 怀孕 |
| **hesitant**（犹豫的） | -ant | hesitan**cy** | 犹豫 |
| **fluent**（流利的） | -ent | fluen**cy** | 流利 |
| **accurate**（准确的） | -ate | accura**cy** | 准确性 |
| **private**（私人的） | -ate | priva**cy** | 隐私 |
| **efficient**（高效的） | -ent | efficien**cy** | 效率 |
| **urgent**（紧急的） | -ent | urgen**cy** | 紧迫性 |

**为什么不用 `-ity`？** 因为发音会很别扭：
- ❌ ~~fluent + ity = fluentity~~ （太拗口）
- ✅ fluent → fluency （流畅自然）

💡 **`-ness` vs `-ity` 怎么选？——看词的"长相"！**

| 用哪个？ | 词的特点 | 例子 |
|:---|:---|:---|
| **`-ness`** | 短（1-2音节）、日常、简单 | happy→happiness, sad→sadness, dark→darkness |
| **`-ity`** | 长（3+音节）、学术、复杂 | possible→possibility, creative→creativity, real→reality |
| **`-cy`** | 以 -ant/-ent/-ate 结尾 | fluent→fluency, accurate→accuracy, private→privacy |
| **`-th`** | 基础测量词（长宽高深强） | long→length, wide→width, strong→strength |

**快速判断流程**：
```
形容词 → 名词
  │
  ├─ 词很短、很日常？ → 用 -ness（happy→happiness）
  ├─ 词较长、较学术？ → 用 -ity（possible→possibility）
  ├─ 以 -ant/-ent/-ate 结尾？ → 用 -cy（fluent→fluency）
  ├─ 可以测量（长宽高）？ → 用 -th（long→length）
  ├─ 表示人生阶段？ → 用 -hood（child→childhood）
  ├─ 表示关系/身份？ → 用 -ship（friend→friendship）
  └─ 表示领域/状态？ → 用 -dom（free→freedom）
```

**应用验证**：
- sad（短词）→ 感觉如何？→ sad**ness**
- possible（长词）→ 本质是什么？→ possibil**ity**
- private（-ate 结尾）→ 到什么程度？→ priv**acy**
- strong（可测量）→ 能量化吗？→ streng**th**
- free → 什么状态/领域？→ free**dom**
- child → 这段时期？→ child**hood**
- friend → 什么关系？→ friend**ship**

##### 公式 2：动词 → 名词（把"动作"变成"东西"）

**核心逻辑：两步判断法**

> 第一步问：**我要表达什么？**（语义维度）  
> 第二步问：**这个动词长什么样？**（形态维度）

---

**第一步：你要表达什么？**

| 你想说的是... | 用这个后缀 | 例子 | 怎么判断？ |
|:---|:---|:---|:---|
| 这个动作/过程本身 | `-tion/-sion`, `-ing` | act → action, swim → swimming | "做某事"的名词化 |
| 动作产生的**具体结果** | `-ment`, `-ure` | develop → development, fail → failure | 能数！(a development) |
| 动作持续的**抽象状态** | `-ance/-ence` | appear → appearance, exist → existence | 不能数！(existence) |
| 这一次具体的动作 | `-al`（动词→名词） | arrive → arrival, approve → approval | "某一次"的事件 |
| 做这件事的人/物 | `-er/-or`, `-ant/-ent` | teach → teacher, act → actor, assist → assistant, study → student | "谁在做？" |
| 被做的人 | `-ee` | employ → employee, train → trainee | "谁被做？" |

**🔍 深入理解 `-ee`：动作的"承受者"**

`-ee` 来自法语/拉丁语的**被动分词**，回答的核心问题是：

> **"这个动作落在谁头上？谁是被动的那一方？"**

**`-ee` vs `-or/-er` 的对照**

这是 `-ee` 最本质的逻辑——它和 `-er/-or` 是一对**镜像关系**：

```
-er/-or → 动作的发出者（谁在做？）
-ee     → 动作的承受者（谁被做？）
```

| 发出者（-or/-er） | ←动作→ | 承受者（-ee） |
|:---|:---|:---|
| **delegat-or**（委派者） | delegate（委派） | **delegat-ee**（被委派者） |
| **employ-er**（雇主） | employ（雇佣） | **employ-ee**（雇员） |
| **train-er**（教练） | train（训练） | **train-ee**（学员） |
| **interview-er**（面试官） | interview（面试） | **interview-ee**（被面试者） |
| **nominat-or**（提名者） | nominate（提名） | **nomin-ee**（被提名人） |

**推导方法——看到任何 `-ee` 结尾的词，这样理解**：

```
动词 + ee = 被[动词]的人

employ + ee  = 被雇佣的人  → 雇员
train + ee   = 被训练的人  → 学员
delegate + ee = 被委派的人 → 受托人
nominate + ee = 被提名的人 → 候选人
refer + ee   = 被推荐的人  → 被推荐人
address + ee = 被致函的人  → 收件人
```

> 💡 **为什么 `delegatee` = 受托人？**
> 
> 老板把一项任务 **delegate**（委派）给你，你就是 **delegatee**——承受"委派"这个动作的人。
> 发出委派的人是 **delegator**，接受委派的人是 **delegatee**。

**⚠️ 少数 `-ee` 不完全是"被动"——但逻辑依然成立**

| 词 | 表面上 | 实际逻辑 |
|:---|:---|:---|
| **refugee** | "避难的人"不像被动？ | refuge（庇护）→ 被给予庇护的人 ✅ |
| **devotee** | "热衷者"不像被动？ | devote（献身）→ 被某事物吸引/投入的人 ✅ |
| **absentee** | "缺席者"不像被动？ | absent（缺席）→ 被记录为缺席的人 ✅ |

> 💡 **记忆口诀**：**`-er` 是做的那个，`-ee` 是被做的那个**——像合同的甲方和乙方。

⚠️ **注意：`-al` 有两种身份！**

| 原词词性 | + `-al` = | 意思 | 例子 |
|:---|:---|:---|:---|
| **动词** | **名词** | 这一次具体的动作 | arrive → arriv**al**, approve → approv**al** |
| **名词** | **形容词** | 和...有关的 | culture → cultur**al**, nation → nation**al** |

> 💡 **简单记忆**：
> - **动词** + `-al` = **名词**（一次事件）：arrival, approval, refusal
> - **名词** + `-al` = **形容词**（有关的）：cultural, national, natural

💡 **`-ment` vs `-ance/-ence` 怎么区分？**

**核心区别：动作"完成了"还是"一直在进行"？**

| | `-ment`（具体产物） | `-ance/-ence`（抽象状态） |
|:---|:---|:---|
| **动作状态** | 动作**完成后**留下的东西 | 动作**一直进行**形成的状态 |
| **能数吗？** | ✅ 能（a development） | ❌ 不能（~~an existence~~） |
| **问什么？** | "做完后留下了什么？" | "这个状态一直在吗？" |

**从动词理解 `-ance/-ence`**：

| 动词 | 动词意思 | → 名词 | 为什么这么翻译？ |
|:---|:---|:---|:---|
| **exist** | 存在着（一直在） | exist**ence** | "一直存在"这件事 = 存在 |
| **appear** | 显现着（一直呈现） | appear**ance** | "一直显现的样子" = 外观 |
| **depend** | 依赖着（一直靠着） | depend**ence** | "一直依赖"这种状态 = 依赖 |
| **perform** | 表演着（持续进行） | perform**ance** | "持续表演"的过程 = 表演/表现 |

> 💡 **为什么 appearance = 外观？**
> 
> 因为你的"外观"就是"你一直呈现(appear)给别人看的样子"！
> appear（显现）一直在发生 → 你的 appearance（外观）

**直观对比**：

```
develop（发展）
   ↓ 动作完成了，留下什么？
development = 一个具体的成果/项目 ✅ 可以数（three developments）

exist（存在）
   ↓ 动作一直在进行，是什么状态？
existence = "存在"这种持续的状态 ❌ 不能数（不说 three existences）
```

**简单记忆**：
- `-ment` = 动作的**产品**（做完了，留下东西）
- `-ance/-ence` = 动作的**状态**（一直在，持续进行）

---

**第二步：看动词的"尾巴"决定具体用哪个**

| 动词结尾 | → 名词后缀 | 为什么？ | 例子 |
|:---|:---|:---|:---|
| `-ate` | → `-ation` | 去 -ate 加 -ation | educate → education |
| `-ify` | → `-ification` | 去 -y 加 -ication | simplify → simplification |
| `-ize/-ise` | → `-ization` | 去 -e 加 -ation | organize → organization |
| `-mit`, `-cede` | → `-ssion` | 双写 s | permit → permission, concede → concession |
| `-vert`, `-pel` | → `-sion` | 改 t/l 为 sion | convert → conversion, expel → expulsion |
| `-ess`, `-ude` | → `-sion` | 去 de/ss 加 sion | confess → confession, conclude → conclusion |
| 短词（1-2音节）| → `-ment`, `-er`, `-ing` | 日耳曼词根偏好 | ship → shipment, read → reader |
| 长词（3+音节）| → `-tion`, `-or` | 拉丁词根偏好 | operate → operation, educate → educator |

---

**完整决策流程图**：

```
动词 → 名词：我该用什么后缀？
  │
  ├─【第一步：语义选择】
  │   ├─ 要表达"动作本身"？ → 往下走，看形态
  │   ├─ 要表达"结果/产物"？ → -ment（常见）或 -ure（固定词）
  │   ├─ 要表达"状态/程度"？ → -ance/-ence
  │   ├─ 要表达"这一次"？ → -al
  │   ├─ 要表达"做的人"？ → -er/-or/-ant/-ent
  │   └─ 要表达"被做的人"？ → -ee
  │
  └─【第二步：形态匹配】（当选择"动作本身"时）
      │
      ├─ 动词以 -ate 结尾？ → educate → educ-ation ✓
      ├─ 动词以 -ify 结尾？ → simplify → simplif-ication ✓
      ├─ 动词以 -ize 结尾？ → organize → organiz-ation ✓
      ├─ 动词以 -mit/-cede 结尾？ → permit → permis-sion ✓
      ├─ 动词是短词（1-2音节）？ → ship → ship-ment ✓
      └─ 都不确定？ → 用 -ing（万能保底）
```

💡 **记忆技巧**：
- **拉丁词**（长、正式）→ 喜欢 `-tion/-sion`, `-or`
- **日耳曼词**（短、日常）→ 喜欢 `-ment`, `-er`, `-ing`
- **不确定词源？** → 用 `-ing` 永远不会错

**应用验证**：
- educate（-ate 结尾）→ 去 ate 加 ation → educat**ion**
- develop → 发展产生了什么？→ develop**ment**
- appear → 出现达到什么程度？→ appear**ance**
- store → 储存涉及什么？→ stor**age**
- fail → 失败后得到什么？→ fail**ure**
- arrive → 这次到达叫什么？→ arriv**al**
- employ → 谁在雇？→ employ**er** / 谁被雇？→ employ**ee**
- assist（-ant 结尾）→ 谁正在帮忙？→ assist**ant**

##### 公式 3：名词 → 名词（概念扩展）

| 后缀 | 语义逻辑 | 你在问什么问题？ | 怎么判断？ |
|:---|:---|:---|:---|
| `-ism` | 这套规则/主义 | "按什么规则玩？" | 表示"一套思想体系" |
| `-ist` | 信奉者/专家 | "谁信奉/精通这个？" | 和 `-ism` 配对 |
| `-ian/-an` | 某领域的人 | "谁在这个领域工作？" | 职业/专业人士 |
| `-ery/-ry` | 场所/行为集合 | "在哪里做/这类行为叫什么？" | 表示"地点/集合" |
| `-let/-ette` | 小型版本 | "小号的叫什么？" | 表示"小的、可爱的" |

**配对记忆**：
```
-ism（主义/规则）←→ -ist（信奉者/专家）
capitalism（资本主义）←→ capitalist（资本家）
socialism（社会主义）←→ socialist（社会主义者）
Buddhism（佛教）     ←→ Buddhist（佛教徒）
tourism（旅游业）   ←→ tourist（游客）
```

**应用验证**：
- capital → 按什么规则？→ capital**ism** / 谁信奉？→ capital**ist**
- music → 谁精通？→ music**ian**
- bake → 在哪里做？→ bak**ery**
- book → 小号的？→ book**let**

##### 公式 4：名词/动词 → 形容词（判断属性）

| 后缀 | 语义逻辑 | 你在问什么问题？ | 怎么判断？ |
|:---|:---|:---|:---|
| `-ful` | 有，适量 | "有这个东西吗？" ✅ | hope**ful**, care**ful**, beauti**ful** |
| `-less` | 没有，完全没有 | "有这个东西吗？" ❌ | hope**less**, care**less**, home**less** |
| `-ous` | 充满，大量 | "这个东西多吗？" ⬆️ | danger**ous**, fam**ous**, nerv**ous** |
| `-y` | 有一些，带点 | "有那个味道吗？" 💦 | rain**y**, snow**y**, sleep**y** |
| `-ish` | 有一点，不完全 | "有一点像？" 🤏 | child**ish**, self**ish**, red**dish** |
| `-al` | 和...有关 | "和什么有关？" | natur**al**, cultur**al**, nation**al**, minim**al** |
| `-ic/-ical` | 具有...的性质 | "有什么特性？" | scientif**ic**, histor**ical**, econom**ic**, scen**ic** |
| `-ive` | 有...倾向 | "爱做什么/有什么倾向？" | act**ive**, creat**ive**, attract**ive** |
| `-able/-ible` | 可以被... | "能被怎样？" | read**able**, vis**ible**, comfort**able** |
| `-en` | 由...制成 | "什么材料做的？" | wood**en**, gold**en**, wool**en** |
| `-like` | 像...一样 | "像什么？"（褒义） | life**like**, child**like**, dream**like** |
| `-ese` | 来自某地 | "来自哪里？" | Chin**ese**, Japan**ese**, Vietnam**ese** |
| `-ant/-ent` | 把动词的"动作"变成形容词的"持续特征 | import**ant**, differ**ent**, independ**ent** |
| `-proof` | 不怕... | "能抵抗什么？" | water**proof**, fire**proof**, bullet**proof** |
| `-oid` | 像但不是 | "像但不是真的？" | human**oid**, aster**oid**, andr**oid** |


**📌 `-ic` 推导示例（名词 → 形容词）：**

| 名词 | + `-ic` | 形容词含义 |
|:---|:---|:---|
| atom（原子） | atom**ic** | 原子的 |
| hero（英雄） | hero**ic** | 英雄的 |
| poet（诗人） | poet**ic** | 诗意的 |
| agent（行动者） | agent**ic** | 有能动性的 |

**🔍 深入理解 `-ant/-ent`：它到底在描述什么？**

`-ant/-ent` 来自拉丁语的**现在分词**，回答的问题是：

> **"这个东西/人持续表现出什么行为特征？"**

**核心逻辑**：把动词的"动作"变成形容词的"持续特征"。

| 词根 | 动作含义 | + `-ant/-ent` | 推导逻辑 |
|:---|:---|:---|:---|
| **differ** | 表现不同 | differ**ent** | 持续表现出不同 → **不同的** ✅ |
| **excel** | 超越别人 | excell**ent** | 持续超越别人 → **卓越的** ✅ |
| **resist** | 抵抗 | resist**ant** | 持续抵抗 → **耐...的** ✅ |
| **consist** | 保持一致 | consist**ent** | 持续保持一致 → **一贯的** ✅ |
| **pati** | 忍耐 | pati**ent** | 持续忍耐 → **有耐心的** ✅ |
| **confide** | 信任 | confid**ent** | 持续信任（自己）→ **自信的** ✅ |
| **abund** | 涌出 | abund**ant** | 持续涌出 → **丰富的** ✅ |
| **perman** | 保持 | perman**ent** | 一直保持 → **永久的** ✅ |

**⚠️ 但 important 是个"假朋友"！**

| 词 | 看起来像... | 实际词源 | 真正含义 |
|:---|:---|:---|:---|
| **important** | import + ant？ | 拉丁语 *importare*（有意义、有关系） | **有重大意义的** |

`important` 不是 "import（进口）+ ant"！它来自拉丁语 *importare*，意思是 "to be of consequence"（有重要意义）。所以：
- ❌ "正在被带入的" → 这是错误的词源分析
- ✅ "具有重大意义的" → 这才是真正的含义

**真正能用 `-ant/-ent` 推导的词**：

| 词 | 推导 | 为什么行得通 |
|:---|:---|:---|
| different | differ（不同）+ ent | "持续表现不同" = 不同的 ✅ |
| excellent | excel（超越）+ ent | "持续超越" = 卓越的 ✅ |
| confident | confide（信任）+ ent | "持续信任（自己）" = 自信的 ✅ |
| patient | pati（忍受）+ ent | "持续忍受" = 有耐心的 ✅ |
| resistant | resist（抵抗）+ ant | "持续抵抗" = 耐...的 ✅ |

**结论**：`-ant/-ent` 的核心是 **"持续做某动作的特征"**，但有些词（如 important）的词源已经偏离了这个规律，需要单独记忆。

**程度量表**：
```
🏜️ -less（没有）→ 💧 -ish（有一点）→ 💦 -y（有一些）→ 💧 -ful（有/适量）→ 🌊 -ous（充满）
```

**`-ful/-less` vs `-ous` 怎么选？——看词的"长相"！**

| 用哪个？ | 词的特点 | 例子 |
|:---|:---|:---|
| **`-ful/-less`** | 短词（1-2音节）、日常 | hope→hopeful/hopeless, care→careful/careless |
| **`-ous`** | 长词（2+音节）、感觉严重 | danger→dangerous, mystery→mysterious |

**快速判断流程**：
```
名词/动词 → 形容词
  │
  ├─ 想说"有没有"？
  │    ├─ 短词 → -ful（有）/ -less（没有）
  │    └─ 长词 → -ous（充满）
  │
  ├─ 想说"和什么有关"？ → -al（长词）或 -y（短词）
  │
  ├─ 想说"可以被..."？ → -able/-ible
  │
  ├─ 想说"有点像"？ → -ish（贬义）或 -like（褒义）
  │
  └─ 想说"什么材料"？ → -en
```

**应用验证**：
- hope（短词）→ 有吗？→ hope**ful** ✅ / hope**less** ❌
- rain（超短）→ 有那个味道？→ rain**y** 💦
- danger（长词）→ 多吗？→ danger**ous** ⬆️
- child → 有点像？→ child**ish** 🤏（贬义）/ child**like**（褒义）
- culture（长词）→ 和什么有关？→ cultur**al**
- science（科学）→ 属于什么领域？→ scient**ific**
- create（-ate结尾）→ 有什么倾向？→ creat**ive**
- read → 能被怎样？→ read**able**
- wood（材料）→ 什么材料？→ wood**en**
- China（国家）→ 来自哪里？→ Chin**ese**
- water → 能抵抗什么？→ water**proof**

##### 公式 5：形容词 → 副词（描述"怎么做"）

| 后缀 | 语义逻辑 | 你在问什么问题？ | 怎么判断？ |
|:---|:---|:---|:---|
| `-ly` | 以...的方式 | "用什么方式做？" | **万能**，几乎所有形容词都行 |
| `-ward/-wards` | 往...方向 | "往哪个方向？" | 只用于**方向**词 |
| `-wise` | 按照...方式/就...而言 | "按什么方式/从什么角度？" | 固定搭配（otherwise, clockwise） |

**应用验证**：
- careful → 用什么方式？→ careful**ly**
- quick → 用什么方式？→ quick**ly**
- forward → 往哪个方向？→ for**ward**/for**wards**
- clock → 按什么方式转？→ clock**wise**
- other → 从什么角度？→ other**wise**

🔑 **规则稳定性**：
- `-ly`：几乎 100% 稳定，所有形容词都能加
- `-ward/-wards`：只用于方向词
- `-wise`：较少见，多用于特定表达

##### 公式 6：名词/形容词 → 动词（"使变成"）

| 后缀          | 语义逻辑    | 你在问什么问题？     | 怎么判断？           |
| :---------- | :------ | :----------- | :-------------- |
| `-ize/-ise` | 使变成某状态  | "怎么让它变成这样？"  | **长词**、抽象概念     |
| `-ify`      | 使具有某特性  | "怎么让它有这个特性？" | **短词**、具体特性     |
| `-en`       | 使变得更... | "怎么让它更...？"  | **超短词**（1音节形容词） |
| `-ate`      | 使...发生  | "怎么让它发生？"    | **科学/技术**动作     |
|             |         |              |                 |
|             |         |              |                 |

**怎么选？看词的"长相"！**

| 用哪个？ | 词的特点 | 例子 |
|:---|:---|:---|
| **`-en`** | 超短词（1音节），基础形容词 | wide→widen, short→shorten, dark→darken |
| **`-ify`** | 短-中等词，具体/简单的变化 | simple→simplify, clear→clarify |
| **`-ize`** | 长词，抽象/正式的变化 | modern→modernize, legal→legalize |
| **`-ate`** | 科学/技术词 | active→activate, motive→motivate |

**快速判断流程**：
```
名词/形容词 → 动词（使变成）
  │
  ├─ 1音节形容词？ → 用 -en（wide→widen）
  ├─ 短词、简单变化？ → 用 -ify（simple→simplify）
  ├─ 长词、正式/抽象？ → 用 -ize（modern→modernize）
  └─ 科学/技术词？ → 用 -ate（active→activate）
```

**应用验证**：
- modern（长词）→ 让它变现代？→ modern**ize**
- simple（短词）→ 让它变简单？→ simpl**ify**
- wide（1音节）→ 让它更宽？→ wid**en**
- active（技术词）→ 让它活跃？→ activ**ate**

##### 公式 7：动词/名词 → 表示人的名词

| 后缀 | 语义逻辑 | 你在问什么问题？ | 怎么判断？ |
|:---|:---|:---|:---|
| `-er/-or` | 做...的人/物 | "谁/什么在做？"（主动） | **短词**用 `-er`，**长词**用 `-or` |
| `-ee` | 被...的人 | "谁被做？"（被动） | 和 `-er/-or` **配对**使用 |
| `-ist` | 专家/信奉者 | "谁专门做/信奉这个？" | **专业/主义**相关 |
| `-ian/-an` | 某领域的人 | "谁在这个领域？" | **学科/职业**相关 |
| `-ant/-ent` | 正在做的人 | "谁正在做？" | 动词以 **-ate/-ent** 结尾 |
| `-ess` | 女性角色 | "女性版本？" | 旧式用法，现在少用 |
| `-ster` | 某类人（非正式） | "属于什么群体？" | **非正式**、有时带贬义 |

**`-er` vs `-or` 怎么选？——看词的"长相"！**

| 用哪个？ | 词的特点 | 例子 |
|:---|:---|:---|
| **`-er`** | 短词（1-2音节）、日常动词 | teach→teacher, work→worker, play→player |
| **`-or`** | 长词（2+音节）、正式动词 | act→actor, direct→director, educate→educator |

**主动 vs 被动——`-er/-or` 和 `-ee` 是英语中最漂亮的"镜像对"**：

> 💡 **核心逻辑**：每个动作都有两端——**发出者**和**承受者**。`-er/-or` 标记发出者，`-ee` 标记承受者。

| 动作 | 发出者（-er/-or） | ←→ | 承受者（-ee） |
|:---|:---|:---|:---|
| employ（雇佣） | **employer**（雇主） | ←→ | **employee**（雇员） |
| train（训练） | **trainer**（培训师） | ←→ | **trainee**（受训者） |
| interview（面试） | **interviewer**（面试官） | ←→ | **interviewee**（被面试者） |
| delegate（委派） | **delegator**（委派者） | ←→ | **delegatee**（受托人） |
| nominate（提名） | **nominator**（提名者） | ←→ | **nominee**（被提名人） |
| license（授权） | **licensor**（授权方） | ←→ | **licensee**（被授权方） |
| pay（支付） | **payer**（付款人） | ←→ | **payee**（收款人） |

```
看到任何 -ee 结尾的陌生词？这样推导：

1. 去掉 -ee，还原动词 → 什么动作？
2. 问"谁被[这个动作]？" → 这就是 -ee 的意思

例：delegatee → delegate（委派）→ 谁被委派？→ 被委派的人 = 受托人 ✅
例：addressee → address（致函）→ 谁被致函？→ 收件人 ✅
例：payee → pay（支付）→ 谁被支付？→ 收款人 ✅
```

**专业程度**：
```
-er（一般做事的人）→ -ist（专家/专业人士）→ -ian（某领域学者/从业者）
worker（工人）    →  specialist（专家）  →  technician（技术员）
```

**快速判断流程**：
```
动词/名词 → 表示人
  │
  ├─ 主动做事的人？（"谁在做？"）
  │    ├─ 短词/日常 → -er（teacher, worker）
  │    └─ 长词/正式 → -or（actor, director）
  │
  ├─ 被动承受的人？（"谁被做？"）
  │    └─ -ee（employee, trainee, delegatee）
  │    💡 推导法：去掉 -ee 还原动词 → "谁被[动词]？"
  │
  ├─ 专家/信奉者？ → -ist（artist, scientist）
  │
  └─ 某领域从业者？ → -ian（musician, technician）
```

**应用验证**：
- teach（短词）→ 谁在教？→ teach**er**
- act（长词感觉）→ 谁在表演？→ act**or**
- employ → 谁被雇？→ employ**ee**
- delegate → 谁被委派？→ delegat**ee**
- art → 谁专门做？→ art**ist**
- music → 谁在这领域？→ music**ian**
- assist（-ant结尾）→ 谁正在帮？→ assist**ant**
- actor → 女性版本？→ actr**ess**
- young → 属于什么群体？→ young**ster**
