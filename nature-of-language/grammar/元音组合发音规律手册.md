## 🔊 `-f / -fe` 复数浊化规律（shelf → shelves）

> 💡 **本质：不是特例，是「为了嘴省力」的物理规律。**

以 `-f / -fe` 结尾的词，变复数时常把 `f` → `v` 再加 `es`。原因纯粹是发音：

```
   shelf  ──►  shel[v]es
    /f/         /v/
   清音          浊音（声带振动）

   清音 f + 浊音 z(es)  → 卡顿  ❌
   浊音 v + 浊音 z(es)  → 顺滑  ✅  shel-ves
```

`es` 读 `/z/` 是浊音，前面若是清音 `/f/` 接起来拗口，**索性把 f 也浊化成 v**，让「浊接浊」，嘴更顺。

### ✅ 遵守浊化的词

| 单数 | 复数 | 释义 |
|:---:|:---:|:---:|
| shel**f** | shel**ves** | 层架 |
| lea**f** | lea**ves** | 叶子 |
| kni**fe** | kni**ves** | 刀 |
| wi**fe** | wi**ves** | 妻子 |
| li**fe** | li**ves** | 生命 |
| hal**f** | hal**ves** | 一半 |
| wol**f** | wol**ves** | 狼 |
| thie**f** | thie**ves** | 小偷 |

### ⚠️ 例外（直接加 s，不浊化）

| 单数 | 复数 | 原因 |
|:---:|:---:|:---|
| roo**f** | roof**s** | 直接加 s 也顺口，无需浊化 |
| chie**f** | chief**s** | 同上 |
| belie**f** | belief**s** | 同上 |
| proo**f** | proof**s** | 同上 |

> 🎯 **判断逻辑**：规律是「为了顺口」——拗口的就浊化成 v，本来就顺口的就保留 f。**不用死记，念一遍哪个顺就选哪个。**
