# 计算机相关词汇

> 不是词典，是理解手册。每个词条揭示**为什么英语这样表达**，让你能举一反三。

---

## 联调 → Integration Testing

**本质**：多个模块/系统第一次连在一起跑通，验证能否协同工作。

**为什么是 integration 而不是 joint debugging？**
- **integrate**（集成）= 把分开的部分合为一体 → 联调的核心动作
- **debug**（调试）= 修 bug → 是出了问题才做的事
- 联调的重点不是"修"，而是"连起来验证" → 所以用 **integration**

| 场景 | 英文 | 逻辑 |
|------|------|------|
| 前后端联调 | integration testing | 前后端集成后的验证 |
| 多系统联调 | end-to-end testing (E2E) | 整条链路从头跑到尾 |
| 和第三方联调 | integration / joint testing | 和外部系统对接验证 |

**常用表达**：
- *We need to do integration testing with the backend.* （和后端联调）
- *The frontend-backend integration is scheduled for next week.* （前后端联调排下周）
- *Let's set up an E2E test environment.* （搭联调环境）
