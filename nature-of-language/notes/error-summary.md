## 一、语法硬伤（会扣分的错误）

### 1. 主谓不一致

```
❌ The percentage of adults aged 65 and over were the smallest
✅ The percentage ... was the smallest
```

**为什么？** 主语是 `the percentage`（单数），不是 `adults`。`of adults` 只是修饰成分，不影响主语的单复数。

### 2. 副词不能做表语

```
❌ Adult fiction and Children's fiction were equally
✅ ... were equally popular / were equal
```

**为什么？** `equally` 是副词，只能修饰形容词/动词，不能跟在 `were` 后面当表语。`were` 后面需要形容词（`equal`）或 `equally + 形容词`（`equally popular`）。

### 3. 句子碎片（Sentence Fragment）

```
❌ Followed by children's non-fiction at 6%.   ← 这不是一个句子！
✅ ...at 13%, followed by children's non-fiction at 6%.  ← 连到上一句
```

**为什么？** `Followed by...` 没有主语，不能独立成句。它是上一句的延续。

### 4. Although 用法错误

```
❌ Although, there are some tiny fluctuations over ten years
✅ ..., although there were some minor fluctuations during the period.
```

**两个错**：
- `Although` 是**连词**，必须连接两个句子，不能像 `However` 那样单独开头加逗号
- `there are` → `there were`：描述过去的数据，用过去时

### 5. 时态混乱

```
❌ the number of loans has a transformation   （现在完成时）
❌ there are some tiny fluctuations           （一般现在时）
✅ the number of loans increased ...          （一般过去时）
✅ there were some minor fluctuations         （一般过去时）
```

**为什么？** 描述图表中过去的数据，统一用**一般过去时**。

## 二、用词搭配问题（不地道）

### 1. `has a transformation` → `increased`

```
❌ the number of loans has a transformation from 16,000 to 22,000
✅ the number of loans increased from 16,000 to 22,000
```

**为什么？** 英语不说 "have a transformation from X to Y"。数据变化直接用动词：`increased / rose / grew from X to Y`。

### 2. `the double figure` → `more than double the figure`

```
❌ which was the double figure of the children (22%)
✅ which was more than double the figure for children (22%)
```

**两个错**：
- 51% ÷ 22% ≈ 2.3，不是正好 2 倍 → 需要 `more than double`
- `the figure for children`（关于儿童的数据），不是 `the figure of the children`（孩子们的数据 → 像是孩子拥有的数据）

### 3. `However` → `By contrast`

```
❌ However, children's DVDs ... were borrowed far less
✅ By contrast, children's DVDs ... were borrowed far less
```

**为什么？** `However` = 转折（前面说 A 好，但其实 A 有问题）。这里不是转折，是**对比**（借得多的 vs 借得少的），用 `By contrast`。

### 4. `biggest` → `largest`

```
❌ the biggest proportion
✅ the largest proportion
```

**为什么？** `proportion / number / amount` 这类可量化的词，搭配 `largest`（客观尺寸），不搭配 `biggest`（口语化）。

## 三、冠词问题

### 1. 多余的 the

```
❌ give the information     → ✅ give information         （引入新信息，不特指）
❌ the library members      → ✅ library members           （泛指所有会员）
```

### 2. 缺少的 the

```
❌ age of library members   → ✅ the age of members        （of 限定后变成特指）
❌ loans trend              → ✅ the trend of loans / the loan trend
```

**规律**：被 `of ...` 后置修饰的名词变成特指 → 加 the。泛指整个类别 → 不加。（这正是冠词手册里讲的逻辑）

## 四、信息完整性

修改版在 introduction 中补充了**时间限定**：

```
原文：including age of library members, total loans by category, and loans trend
```
