# 对话记录 - 词汇与句子理解 3

## mean 到底是几个词？

### 问题
mean 有 n v 的意思，n 吝啬，V 意味着/打算，meant 过去式/过去分词，meaning 是另一个词 n 意义？到底是几个独立的词？

### 解答

严格来说是 **三个同形异源词**（homonyms）：

| # | 词 | 词源 | 词性 | 核心义 |
|---|---|---|---|---|
| 1 | mean | 古英语 *mǣnan* | **动词** | 意味着 / 打算 |
| 1a | meaning | ← mean 动词 + -ing | 名词 | 意义（派生，不是独立词） |
| 2 | mean | 古英语 *gemǣne* | **形容词** | 吝啬 / 刻薄 |
| 3 | mean | 法语 *moyen* | **形容词/名词** | 平均（值） |

- `meant` 和 `meaning` 都只属于第 1 个（动词）
- "吝啬"是**形容词**，不是名词
- `meaning` 不是独立的另一个词，是 mean（动词）的 `-ing` 派生名词，跟 feeling（← feel）、building（← build）一样的构词逻辑

## "被称为"的英语表达：called vs named

### 核心表达

| 表达 | 语感 | 例句 |
|------|------|------|
| **called** | 最通用、最口语 | This is called a "suffix". |
| **named** | 强调"名字是什么"（专有名称） | a boy named Tom |
| **known as** | 正式，强调"以…身份为人所知" | He is known as the King of Pop. |
| **referred to as** | 最正式，学术/书面 | This phenomenon is referred to as "inflation". |
| **termed** | 学术专用 | This is termed "cognitive dissonance". |

### called vs named 的核心区别

问的问题不同：

- **named** → "它的名字（name）是什么？" → 侧重**专有名称**
  - a city named Paris / a girl named Alice

- **called** → "人们怎么叫（call）它？" → 侧重**通称/泛称**，范围更广
  - This tool is called a wrench.
  - What is this called?（日常问"这叫什么"）

简单判断：
- 给人/地点起的正式名字 → `named` 更自然
- 描述事物的通用叫法 → `called` 更自然
- 两者大多数情况可互换，`called` 适用面更广

### name 和 call 此时都是动词

- **name**（动词）= 给…命名 → "They **named** the baby Tom."
- **call**（动词）= 称呼…为 → "They **call** it a bug."

`named Tom` 和 `called a bug` 都是动词的过去分词作后置定语/补语，本质是被动：

- a boy named Tom = a boy **who was named** Tom
- This is called X = This **is called** X

## Named volumes 中的 named

**Named volumes** = 被命名的卷 = 有名字的卷

- `named` = 过去分词作前置定语，修饰 `volumes`
- 相当于 "volumes that have been named"

Docker 中的对比：

| 类型 | 含义 |
|------|------|
| **named** volumes | 有名字的卷（你主动给它取了名） |
| **anonymous** volumes | 匿名卷（没给名字，Docker 自动分配随机 ID） |

过去分词完全形容词化的例子：a locked door、a broken window、a named volume

## baked-in 的含义

**baked-in** = 内置的、固有的、已经嵌入其中不可更改的

### 来源逻辑

字面意思：烤进去的（bake = 烘烤）

想象把巧克力片揉进面团里再烤 → 烤完之后巧克力就**永久嵌在里面了**，没法拿出来。

引申义 = **从一开始就内建在里面、不可分离、不可轻易修改的**。

### 常见用法

| 例句 | 含义 |
|------|------|
| Security is **baked into** the design. | 安全性从设计之初就内置了 |
| These assumptions are **baked-in**. | 这些假设是固有的/硬编码的 |
| The bias is **baked into** the model. | 偏见已经嵌入模型中了 |

### 近义词对比

| 词 | 语感 |
|------|------|
| **baked-in** | 强调"从一开始就在里面，很难改" |
| **built-in** | 内置的（中性，最通用） |
| **hard-coded** | 硬编码的（技术用语，强调写死了） |
| **inherent** | 固有的（正式/学术） |

## 为什么是 baked-in / built-in 而不是 bake-in / build-in？

因为这里需要的是**形容词**（描述状态），不是动词（描述动作）。

**过去分词 = 动作完成后的结果状态**，天然适合当形容词：

- bake（烤）→ baked（被烤过的）→ baked-in（被烤进去的 = 内置的）
- build（建）→ built（被建好的）→ built-in（被建在里面的 = 内置的）
- lock（锁）→ locked（被锁上的）
- break（打破）→ broken（被打破的）

`bake-in` / `build-in` 会被理解为**动词短语**（命令/动作），不是形容词：

- ✅ "Please **bake in** the chocolate chips."（动词：把巧克力烤进去）
- ✅ "The feature is **baked-in**."（形容词：这个功能是内置的）
- ❌ "a **bake-in** feature"（语法错误，动词原形不能直接当定语）

## built / baked 是过去分词还是过去式？

**两者都是。** 同一个形式身兼两职。

| 动词 | 过去式 | 过去分词 | 两者相同？ |
|------|------|------|------|
| bake | baked | baked | ✅ 相同 |
| build | built | built | ✅ 相同 |
| break | broke | broken | ❌ 不同 |
| go | went | gone | ❌ 不同 |

### 怎么区分它在句子里是哪个？看语法位置：

| 用法 | 身份 | 例句 |
|------|------|------|
| 和主语直接搭配，表示过去的动作 | 过去式 | He **built** a house. |
| 跟在 have/has/had 后面 | 过去分词 | He **has built** a house. |
| 跟在 be 后面（被动） | 过去分词 | The house **was built** in 1990. |
| 当形容词用 | 过去分词 | a **built-in** feature |

大多数英语动词的过去式和过去分词长得一样（worked, called, baked, built），只有部分不规则动词才会不同（break/broke/broken, go/went/gone）。不是"它是哪个"的问题，而是"它在句子里扮演哪个角色"的问题。
