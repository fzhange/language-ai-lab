## that that 双 that 结构

**原句：** China is giving President Trump a welcome ceremony that rivals that of KING CHARLES when he visited the United States

### 拆解

| that | 功能 | 指代 |
|------|------|------|
| 第一个 **that** | 关系代词，引导定语从句 | = which，修饰 a welcome ceremony |
| 第二个 **that** | 指示代词，替代前面提到的名词 | = the welcome ceremony |

### 还原逻辑

把两个 that 都换回它们代替的东西：

> China is giving Trump **a welcome ceremony** [**which** rivals **the welcome ceremony** of King Charles]

为了避免重复说两次 "welcome ceremony"，英语用：
- 第一个 that → 关系代词，连接从句
- 第二个 that → 指示代词，替代已提过的名词

### "that of" 是高频结构

**"that of + 名词"** = 前面提到的那个东西（属于某人/某物的）

这是英语中**避免重复**的标准手段：

> The population of China is larger than **that of** Japan.
> （中国的人口比日本的（人口）大）

> His accent is similar to **that of** a native speaker.
> （他的口音和母语者的（口音）很像）

核心逻辑：**that = 前面已经说过的那个名词**，用 `of` 限定是"谁的"。看到 `that of` 时，往前找它替代的是哪个名词就行。

## undergraduate degree 为什么是"学位"而不是"在读"

### 核心区别

| 表达 | 视角 | 含义 |
|------|------|------|
| undergraduate | 站在**过程**中看 | 正在读本科的人/阶段 |
| undergraduate degree | 站在**结果**上看 | 本科阶段完成后获得的学位 |

### 为什么能这么用？

`undergraduate` 在这里是**形容词**，修饰 `degree`，描述学位属于哪个**层级**：

```
undergraduate degree  → 本科层级的学位（= bachelor's degree）
graduate degree       → 研究生层级的学位（= master's / doctoral degree）
```

**degree 是完成学业后被授予的东西**，所以 `undergraduate degree` 自动隐含了"已完成"。

类比中文："本科学历" — 没人觉得这意味着你还在读。

---

## postgraduate degree 的层级关系

```
postgraduate degree（研究生学位）
├── master's degree（硕士学位）
└── doctoral degree / PhD（博士学位）
```

| 表达 | 精确度 | 含义 |
|------|--------|------|
| postgraduate degree | 笼统 | 研究生学位（硕士或博士都算） |
| master's degree | 精确 | 专指硕士 |
| doctoral degree / PhD | 精确 | 专指博士 |

因为研究生学位有更具体的名字，日常交流中人们更倾向说具体的。而本科学位只有一种，所以 `undergraduate degree` ≈ `bachelor's degree`。

## How do you do? 为什么是"你好"

### do 的古义

这里的 **do** 不是"做事"，而是古老含义：**过日子、过得如何**（= fare, get along）

```
How do you do? = 你日子过得怎样？→ 固化为正式问候"你好"
```

### 判断方法

如果要问"你怎么做某事"，必须有宾语：

```
How do you do it?   → 你怎么做这件事的？（有 it）
How do you do?      → 没有宾语 → do = 过活 → 你好
```

---

## How's it going? 中的 it

这个 **it** 是虚义 it，指代"生活/一切"这个模糊整体：

```
How's it going? = How is [your life/everything] going? = 你最近怎么样？
```

### 判断方法

```
有具体前文 → it = 那个东西 → "它怎么样？"
没有前文/打招呼 → it = 生活整体 → "你怎么样？"
```

## appear vs appeal

| 词 | 拆解 | 核心意象 |
|------|------|----------|
| **appear** | ap- + **par**（可见的） | **变得可见** |
| **appeal** | ap- + **peal**（驱动/推） | **发出拉力** |

### 一句话区分

```
appear = 东西"显现"在你眼前（视觉）
appeal = 东西"拉"你过去（力量）
```

| appear（显现） | appeal（拉力/召唤） |
|------|------|
| 出现：A man appeared at the door. | 吸引：This appeals to me. |
| 看起来：She appears tired. | 呼吁：He appealed for help. |
| 似乎：It appears that... | 上诉：They appealed the decision. |

发音差异：appear /əˈpɪr/（结尾 -r）vs appeal /əˈpiːl/（结尾 -l）

## Tier-1 fund

**Tier** = 层级（金字塔的一层）

```
Tier-1 = 最顶层 = 最顶级的
```

**Tier-1 fund** = 顶级基金（行业里最头部、最有影响力的基金）

通用用法：Tier-1 city（一线城市）、Tier-1 university（顶尖大学）

## Time to finish strong!

**是时候强势收尾了！**

- `finish strong` = 强势收尾 / 冲刺结束
- **strong** 这里是 flat adverb（形容词直接当副词用），类似 run fast、hit hard

## gearing up

**准备就绪 / 蓄势待发**

**gear** 本意是齿轮/档位：

```
gear up → 把齿轮挂上 → 进入工作状态 → 做好准备
```

- gear up for + 事情：We're gearing up for the launch.
- 比 prepare 更有动感和紧迫感

## bullet points

**bullet point = 要点前面的小圆点 •**

bullet 本意是"子弹"，那个 • 符号像子弹头所以叫 bullet。

"3 bullet points" = 3 个简洁的要点（暗示列表格式、短小精悍），不只是"三点"。

## spanning（span 的用法）

**span 的核心意象** = 张开手掌的跨度 → 从一端到另一端

```
spanning 1.22 million square meters = 占地 122 万平方米
```

| 场景 | 例句 | 含义 |
|------|------|------|
| 空间 | The park spans 500 acres. | 占地 |
| 时间 | His career spanned 30 years. | 跨越 |
| 抽象 | The project spans multiple departments. | 涉及 |

## floor area

floor 在这里 = 楼层（不是地板）

|------|------|
| floor area | 建筑面积（所有楼层之和） |
| land area | 占地面积（地块大小） |

## groom：从"照料"到"新郎"

### 词源演变链

```
groom 原始义 = 男仆、侍从
→ 男仆照料马匹 → 动词"打理、梳洗"
→ bridegroom（新娘的侍从/伴侣）→ 简称 groom = 新郎
```

| 用法 | 含义 |
|------|------|
| groom a horse | 给马梳毛清洗 |
| well-groomed | 仪表整洁的 |
| groom sb for a role | 培养某人担任某职 |
| the groom | 新郎 |

核心都是"照料、打理"的延伸。

## slip vs slide

### 核心区别

```
slip = 意外地滑（失控）→ 踩到香蕉皮
slide = 顺畅地滑（可控）→ 滑滑梯
```

| slip（意外滑） | slide（顺畅滑） |
|------|------|
| I slipped on the ice. 脚滑摔倒 | Kids slid down the slide. 滑下滑梯 |
| The phone slipped out of my hand. 滑落 | She slid the door open. 推拉门滑开 |

延伸义同样遵循：
- slip of the tongue = 口误（不小心）
- slide into DMs = 滑进私信（主动）
- let it slip = 不小心泄露
- let things slide = 放任不管

名词：a slip = 小差错/纸条；a slide = 滑梯/幻灯片（PPT 一页）
