# 📖 Nature of Language

> **Understand, Don't Memorize.**。

This project provides a series of English language manuals that reveal the **underlying logic** of English grammar and vocabulary. Our goal is to help learners **infer and deduce** rather than **rote memorize**.

---

## 🎯 Core Philosophy

### **ROTE IS FORBIDDEN.**

Every piece of content must reveal **universal logic** that enables readers to **understand and infer**, not memorize.

> "Give a man a fish and you feed him for a day. Teach a man to fish and you feed him for a lifetime."

We teach **fishing** — the universal logic of English — not give **fish** — lists of words to memorize.

---

## ✅ What We DO

| Principle | Description |
|:---|:---|
| 🔍 **Reveal the "WHY"** | Explain the underlying logic behind every rule, not just the pattern |
| 📐 **Provide Universal Formulas** | Give transformation logic that applies broadly (e.g., "Who does it?" → `-er`) |
| 🔗 **Show Relationships** | Connect related concepts — opposites, synonyms, transformation chains |
| 📊 **Use Visual Logic** | Diagrams, flowcharts, decision trees to make abstract logic concrete |

---

## ❌ What We DON'T DO

| Anti-Pattern | Why It's Wrong | What We Do Instead |
|:---|:---|:---|
| ❌ Pure lists for memorization | "Memorize these 50 words" teaches nothing | ✅ Explain WHY the pattern exists |
| ❌ Examples without logic | Listing without explaining is useless | ✅ Show the semantic question each pattern answers |
| ❌ Rules without reasoning | "Just remember" is not teaching | ✅ Explain the underlying principle |
| ❌ Exceptions without context | Random exceptions frustrate learners | ✅ Explain historical/phonetic reasons |

---

## 📐 Content Structure

Every section follows this structure:

```
1. What is the CORE LOGIC? (the nature)
2. What QUESTION does it answer? (semantic function)
3. How can readers APPLY it? (inference method)
4. What are the BOUNDARIES? (when it doesn't apply, and why)
```

---

## 🧪 Quality Self-Check

Before any content is finalized, it must pass these checks:

- [ ] Can a reader **deduce** new examples using this logic?
- [ ] Does this explain **WHY**, not just **WHAT**?
- [ ] Is there a **universal pattern** that applies beyond the examples?
- [ ] Would removing the examples still leave useful knowledge?

**If NO to any of these → Rewrite.**
