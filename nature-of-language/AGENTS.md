# nature-of-language — 语言学习知识库（给 AI Agent 的上下文文档）

> 先读工作区总览：`../AGENTS.md`。本仓库是**纯内容仓库**（Markdown 笔记），不含可执行代码。

## 目标与定位

英语学习笔记库，核心哲学：**"理解而非死记"（Understand, Don't Memorize）**——揭示语法和词汇的底层逻辑，而非罗列规则。在整个系统中充当 **Agent 的知识库内容源**：`generic-agent-service` 的导师 Agent 以**只读**方式检索本仓库内容来回答用户问题。

## 目录结构

| 目录 | 内容 | 规模 |
|---|---|---|
| `grammar/` | 语法专题深度拆解（介词、动词、冠词、后缀、倒装、比较、标点等） | 16 篇 |
| `notes/` | 学习笔记、错题总结、AI 对话记录 | 6 篇 |
| `tech/` | 技术英语词汇笔记（含每日记录 26M7/26M8/26M9） | 6 篇 |
| `Ielts/` | 雅思备考（写作目标 6.5），`writings/YYYY-MM-DD/` 按日期归档写作练习 | 4 篇 |
| `blog/` | 英语随笔 | 2 篇 |
| 根目录 | 词汇手册（近义词、词源拆解等）+ 项目说明 | 6 篇 |

共约 40 篇、500KB。命名特征：大量 `XX完全理解手册.md`，部分文件名带 emoji（如 `😁 标点符号完全理解手册.md`）——**检索时注意兼容 emoji 文件名**。

## 内容约定（写作/修改笔记时遵守）

- 无 YAML frontmatter，无统一标签体系
- 每个专题的软性四段结构（见 `README.md`）：**核心逻辑 → 回答什么问题 → 如何推导应用 → 边界/例外**
- 典型元素：标题下紧跟 `> 原则` 引用块、ASCII 示意图/决策树、`❌/✅` 对错对比表、Obsidian callout（`> [!tip]`）
- **中英混排：中文解释，英文示范**
- 雅思写作批改按 TR/CC/LR/GRA 四维度；写作练习结构：📝 原文 → ✏️ 修改后版本 → 🔬 本质性问题精讲

## 与其他仓库的关系

- **被 `generic-agent-service` 只读检索**：Agent 通过 `search_notes(keyword)` / `read_note(path)` 工具访问（按相对路径），本仓库不需要为此做任何改动
- **被 `words-highlight-in-web` 间接关联**：用户高亮的网页句子，Agent 可结合本仓库的语法/词汇笔记讲解
- 内容变更会直接改变 Agent 的知识回答质量——修改笔记时注意保持结构清晰、结论明确
