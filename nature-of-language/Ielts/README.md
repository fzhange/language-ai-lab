# IELTS 学习目录

## 目标

**写作目标分数：6.5**

## 目录结构

```
Ielts/
├── writings/          # 写作练习（日常写作记录）
│   └── YYYY-MM-DD.md  # 按日期命名的写作文件
├── (listening/)       # 听力 - 待建
├── (reading/)         # 阅读 - 待建
├── (speaking/)        # 口语 - 待建
└── README.md          # 本文件
```

## 写作目录说明 (`writings/`)

- 用于记录日常英语写作练习
- 文件以日期命名，格式：`YYYY-MM-DD.md`
- 内容可以是雅思写作真题练习、日常话题写作、或任何英语写作训练

## AI 辅助原则

在帮助批改或反馈写作时，应遵循：

1. **指出问题时说明 WHY** — 不只标记错误，要解释错误背后的语法/逻辑原因
2. **给出提升建议** — 针对 6.5 分标准，指出哪些地方可以提升以及如何提升
3. **关注四项评分维度**：
   - **Task Response (TR)** — 是否完整回答了题目要求
   - **Coherence & Cohesion (CC)** — 逻辑连贯性和衔接
   - **Lexical Resource (LR)** — 词汇丰富度和准确性
   - **Grammatical Range & Accuracy (GRA)** — 语法多样性和准确性
4. **用中文解释，用英文示范** — 解释用中文确保理解，改进示例用英文
