# Words Highlight in Web · 用户手册

一个帮你**在任意网页上高亮单词/句子并做笔记**的浏览器扩展。适合语言学习、文献阅读、资料整理——把网页当成你的可标注笔记本。

支持 Chrome / Edge / Brave（Chromium 内核，版本 105+）。

## 一、安装

> 如果你是普通用户，拿到的是打包好的扩展，请直接看第 2 步。

### 1. 构建（开发者）

```bash
npm install
npm run build
```

构建产物在 `dist/chrome-mv3/`。

### 2. 加载到浏览器

1. 打开 `chrome://extensions`（Edge 是 `edge://extensions`）。
2. 打开右上角「**开发者模式**」。
3. 点「**加载已解压的扩展程序**」，选择 `dist/chrome-mv3/` 目录。
4. 建议把扩展**固定到工具栏**（点拼图图标 → 找到本扩展 → 点图钉）。

加载完成即可使用，数据自动保存在浏览器本地。

## 二、快速上手（30 秒）

1. 打开任意网页，**选中一段文字**。
2. 页面顶部弹出取色条，**点一个颜色** → 文字被高亮。
3. 点扩展图标，能看到刚加的高亮。
4. 刷新页面，高亮自动恢复。

就这样，已经会用了。下面是完整功能。

## 三、高亮

### 添加高亮（三种方式，任选）

| 方式 | 操作 |
|------|------|
| **取色条** | 选中文字 → 顶部弹出的取色条点颜色 |
| **右键菜单** | 选中文字 → 右键「高亮所选内容」→ 选颜色或「用上次的颜色」 |
| **快捷键** | 选中文字 → 按 `Alt+H`（Mac 为 `Option+H`），直接用上次颜色 |

### 15 种颜色

黄 · 琥珀 · 橙 · 红 · 粉 · 玫红 · 紫 · 靛紫 · 蓝 · 天蓝 · 青 · 蓝绿 · 绿 · 黄绿 · 灰

> 你可以给颜色赋予自己的语义，比如：黄 = 生词，绿 = 重点，红 = 存疑。

### 修改颜色

**点击**已高亮的文字 → 在弹出的工具条上点新颜色即可。

### 删除高亮（三种方式）

| 方式 | 操作 |
|------|------|
| **Delete 键**（推荐） | 点击高亮弹出编辑条 → 按 `Delete` 或 `Backspace` |
| **工具条按钮** | 点击高亮 → 点工具条上的「删除」 |
| **全局快捷键** | 鼠标悬停在高亮上 → 按 `Alt+Shift+H`（Mac 为 `Option+Shift+H`） |

> Delete 键方式最自然：先点中，再删。焦点在笔记输入框里时，Delete 键是正常编辑文字，不会误删。

### 关闭弹出的工具条

点页面空白处，或按 `Esc`。

## 四、笔记与心得

高亮不只是染色，还能给每段内容记录**两类**想法：

- **笔记**：针对原文的**翻译、词义、用法、注释**——"这段话是什么意思"。
- **心得**：对内容的**概念理解、感悟、联想、疑问**——"这让我想到什么"。

两者独立、可只填其一，也可以都写。

### 添加 / 编辑

1. 选中文字（或点击已有高亮）→ 工具条点「**笔记**」。
2. 下方展开编辑面板（顶部显示被引用的原文），里面有**两个输入区**：上面是「笔记」，下面是「心得」。
3. 分别填写后点「**保存**」，或按 `⌘/Ctrl + Enter` 快捷保存。

> 打开面板时，如果还没写笔记会先聚焦「笔记」；已有笔记则聚焦「心得」，符合"先翻译、后感悟"的顺序。

### 查看

- **带笔记或心得的高亮有虚线下划线**，一眼可辨。
- **鼠标悬停**在上面，浮出深色气泡，「笔记」「心得」**左右并排**显示。
- 气泡**可以选中文字、可以点击**：把鼠标移到气泡上不会消失；每个面板右下角有「**编辑**」（打开编辑面板）和「**复制**」（复制该面板内容）按钮。
- 工具条的「笔记」按钮在有内容时显示为「**笔记 •**」。

### 小贴士

- 编辑面板的左侧竖线、聚焦框、保存键颜色会**跟随该高亮的颜色**，视觉统一。
- 笔记和心得都会随高亮一起保存、一起同步、一起导出。
- 弹窗和管理页里，笔记（黄色底）和心得（橙色底）分开展示，搜索也会同时匹配两者。

## 五、快捷键一览

> Mac 上的 `Alt` 就是 `Option(⌥)` 键。所有快捷键都可以在 `chrome://extensions/shortcuts` 自行修改。

| 快捷键 | Mac | 作用 |
|--------|-----|------|
| `Alt + H` | `Option + H` | 用上次的颜色高亮当前选区 |
| `Alt + Shift + H` | `Option + Shift + H` | 删除正在编辑 / 鼠标悬停的高亮 |
| `Delete` / `Backspace` | 同左 | 点中某条高亮后，删除它 |
| `⌘/Ctrl + Enter` | `⌘ + Enter` | 在笔记面板中保存笔记 |
| `Esc` | 同左 | 关闭取色条 / 编辑面板 |

> 提示：Chrome 限制每个扩展最多注册 4 个全局快捷键，我们用了 2 个（`Alt+H`、`Alt+Shift+H`），`Delete`/`Esc` 是页面内监听、不占名额。

## 六、弹窗：管理当前页

点击浏览器工具栏的**扩展图标**，弹出当前页的高亮列表。

- 每条显示：颜色圆点 + 高亮原文 + 笔记（如有）。
- **点击某条** → 页面自动滚动到那条高亮的位置，并关闭弹窗。
- **点「×」** → 删除该条。
- 底部「**清空本页**」→ 删除当前页所有高亮（谨慎）。
- 底部「**管理全部**」→ 进入全局管理页。

## 七、管理页：全局管理

在弹窗点「管理全部」，或在 `chrome://extensions` 找到本扩展 → 「扩展程序选项」，打开管理页（整页标签）。

### 两种视图

- **所有高亮**（默认）：跨页面平铺所有高亮，按时间倒序。每条下方显示来源页面，**点来源可跳回原页并自动定位**到那条高亮。
- **按页面**：按网页分组，可整页删除。

### 搜索

顶部搜索框，按**高亮原文**或**笔记内容**实时过滤，两种视图都生效。

## 八、数据与备份

### 数据存在哪

采用**「本地缓存 + 云端同步」**两层架构：

- **本地缓存**（`chrome.storage.local`）：所有读写先走本地，**离线、未登录都能正常用**，速度快。
- **云端**（Supabase）：登录后数据自动同步到云端，多台设备共享。

### 登录与开启同步

1. 打开管理页，在「**云同步**」卡片填邮箱 + 密码。
2. 首次使用点「**注册**」，之后（含另一台电脑）点「**登录**」。
3. 两台电脑登录**同一账号**即自动同步。

> 账号由 Supabase Auth 托管，数据安全靠行级权限（RLS)：你只能读写自己的数据。

### 同步规则（重要）

了解这些规则，就明白数据是怎么在多设备间保持一致的：

**什么时候同步**
- 本地每次**新增/修改/删除** → **立即**推送云端（尽力而为，失败不阻塞本地）。
- **每 5 分钟**自动 + **浏览器启动时** + 手动点「**立即同步**」→ 做一次**双向全量对齐**。

**对齐规则（双向 reconciliation）**
| 情况 | 结果 |
|------|------|
| 云端有、本地没有 | 补充到本地 |
| 本地有、云端没有 | 推送到云端 |
| 两边都有、云端更新 | 覆盖本地 |
| 两边都有、本地更新 | 推到云端 |
| 时间一样 | 不动 |

**删除怎么同步（软删除 / 墓碑）**
- 本地删除后，云端**不会物理删除该行**，而是打上 `deleted_at` 时间戳（墓碑），用于通知其他设备"这条已删"。
- 所以你在 Supabase 后台仍可能看到"已删"的行，属正常。
- **离线删除**也不怕：本地有删除清单兜底，下次同步会补删，**不会被云端旧数据复活**。
- 云端墓碑**超过 7 天**会被自动**物理清除**，数据库保持干净。

**冲突怎么解决**
- 同一条高亮在两台设备都改了：以 **`updated_at` 时间较新者**为准（last write wins）。

### 导出备份

管理页点「**导出 JSON**」→ 下载一个带日期的 `.json` 文件，包含所有页面、所有高亮和笔记。

### 导入恢复 / 迁移

管理页点「**导入**」→ 选择之前导出的 `.json` 文件：

- 按 URL 把高亮归并到对应页面；
- 按 id **去重**，不会重复导入、也**不会覆盖**你现有的高亮；
- 完成后提示新增了多少条。

> 从别的电脑迁移数据：在旧电脑「导出」，把文件传到新电脑「导入」，再点「立即同步」即可同步到云端、并分发到所有设备。

### ⚠️ 重要

- **未登录时数据只存在本机**，不会上云；登录后点「立即同步」才会把本地数据推上去。
- **卸载扩展**或**清除浏览器数据**会删除本地副本；已同步到云端的数据重新登录后可拉回，重要数据仍建议定期「导出 JSON」。
- 导入是"增量合并"，想完全重置请先在各页面清空或使用「按页面」删除。

## 九、常见问题 FAQ

**Q1：选中了文字，但没有弹出取色条？**
- 该页可能是浏览器内置页（`chrome://`、扩展商店、PDF 查看器等），这类页面禁止注入脚本，属正常限制。
- 试试普通网页（如新闻、文档站）。

**Q2：刷新后某条高亮不见了？**
- 高亮靠"文本内容 + 上下文"定位。如果网页正文被大幅修改，个别高亮会锚点失效。这是机制使然，静态内容（文档、博客）基本都能稳定恢复。

**Q3：快捷键没反应？**
- 到 `chrome://extensions/shortcuts` 检查按键是否被其它扩展/系统占用，可在这里改成你顺手的键。
- Mac 上注意：`Alt` 就是 `Option` 键；`Command+H` 是系统"隐藏窗口"，无法用。

**Q4：高亮会破坏原网页样式吗？**
- 不会。我们用浏览器原生的 CSS Custom Highlight API 渲染，**完全不改动网页的 DOM**，只是给文字"叠加"一层背景色。

**Q5：取色条为什么固定在页面顶部？**
- 为了避免和豆包等划词翻译插件在选区附近的弹窗互相遮挡，我们把取色条固定在视口顶部居中。

**Q6：笔记输入框右下角有个小图标（Grammarly 之类）？**
- 那是你装的其他语法检查扩展注入的，与本扩展无关。我们已对输入框做了抑制标记，若仍出现可在该扩展设置里对本站关闭。

**Q7：数据会同步到我的另一台电脑吗？**
- 会。两台电脑在管理页登录**同一 Supabase 账号**即自动同步（本地缓存 + 云端双向对齐）。未登录时数据只存本机，也可用「导出 / 导入」手动迁移。详见「八、数据与备份」的同步规则。

**Q8：我在 Supabase 后台删除/看到的行和插件里对不上？**
- 本地删除是**软删除**（行保留但 `deleted_at` 有时间戳），不是物理删除，所以后台仍可能看到这些行，属正常；超过 7 天会自动物理清除。
- 扩展里的数据以本地缓存为准，点「立即同步」即可与云端双向对齐。

## 十、使用技巧

- **语言学习**：生词用黄色 + 笔记写释义例句、心得写用法感悟；搭配「所有高亮」视图，就是一本随时回顾的生词本。
- **文献阅读**：重点绿、存疑红、待查橙；笔记记要点、心得写批判性思考，事后在管理页按颜色回忆结构。
- **快速连续标注**：选中 → `Alt+H`（上次颜色）连击，不打断阅读节奏。
- **定期导出**：把「导出 JSON」当成存档习惯，配合笔记，等于把网页阅读沉淀成自己的知识库。
